# MAGPIE 부품 조립 시범

기준: 2026-09-11. 사용자 승인에 따라 알아볼 수 있는 총기·파지·견착을 우선한 정지 조준 자세 실험입니다.

- 원본 1254×1254의 몸체, 총기+양손, 헬멧+방탄복 3개 층을 실제로 겹칩니다. 부품별 이동·회전·배율 보정 없이 같은 좌표를 사용합니다.
- 전체를 함께 회전할 수 있고, 각 부품을 끄거나 켜서 실제 겹침을 확인할 수 있습니다.
- `public/art-review/magpie-modular-v1/index.html`에 연결했습니다. 경기의 인물 상태 선택기를 바꾼 작업은 아닙니다.
- `prepare.py`는 기존 키 제거기를 재사용해 투명화·무손실 압축만 합니다. 신체나 총기 형태를 코드로 그리지 않습니다.
- 브라우저와 같은 `compose.mjs`를 `node tests/modular-sprite-pilot.cjs`에서 실행해 좌표, 총구, 발·손목 접점 픽셀, 투명 배경, 표시 토글을 검사했습니다. 실제 브라우저·아이폰 검사와 애니메이션 검증은 미수행입니다.
- 실제 재조립 화면: `validation/magpie-modular-review.png`. 128px·64px 축소 비교에서는 세부 파지보다 전체 실루엣이 먼저 읽힙니다. 확대 연출이 여전히 중요합니다.

## 제작·검수 이력

내장 imagegen 6회: 첫 조립 보드 2개, 수정 기준 원화 1개, 그 원화에서 부품 분리 3개. 첫 보드는 추가 다리와 총기 시점 불일치, 두 번째는 부품 위치와 팔 접점 불일치로 채택하지 않았습니다. 채택한 기준 원화와 부품 원본만 이 폴더에 보존합니다. 프롬프트는 `prompts.json`입니다.

장점은 한번 검수한 총기·손 묶음을 같은 자세에서 재사용할 수 있다는 점입니다. 최초 제작에 6회가 들었으므로 이 시범만으로 총 사용량 절감을 검증했다고 말할 수 없습니다.

## 한계와 다음 검증

총기와 손은 아직 독립된 골격이 아니며, 헬멧과 방탄복도 한 층입니다. 몸체는 남성 한 체형·정지 조준 한 자세입니다. 걷기, 장전, 자세 전환, 다른 무기·체형으로의 재사용은 아직 검증하지 않았습니다. 장전에는 탄창과 지지 손의 별도 접점·가림 순서를 검증해야 합니다.

L119A2 짧은 형상의 제조사 사진과 일체형 상부·황갈색 개머리판/손잡이 설명을 참고했습니다. 제조사 사진은 게임 자산에 포함하지 않았습니다. 세부 부품, 광학장비 모델, 실제 부대 지급 장구까지 고증 완료로 판정하지 않습니다.
