# Minimalist Military — 공통 파츠 1차

2026-09-11 사용자의 아트 전환 요청에 따른 신규 원본입니다. 내장 이미지 생성으로 몸체 1회, 뒷면 오류 수정 1회, 머리 1회를 수행했습니다. 실사형 모듈 시범의 이전 6회와 별개입니다. 비용 절감 배율은 측정하지 않았습니다.

- body-source.png: 앞·뒤·옆 몸체. 첫 결과의 뒤쪽 앞 파우치를 수정했습니다. 수정 결과가 불투명 체크 배경을 반환해 외곽에 연결된 중립색 배경만 제거했습니다.
- heads-source.png: 헬멧/고글형과 방독면형의 세 방향. 실제 alpha를 유지했습니다.
- prepare.py: 배경 제거, 셀 분리, 종횡비 유지 축소만 수행합니다. 해부학을 다시 그리지 않습니다. parts.json에 자르기 영역·공통 피벗을 기록합니다.
- 결과 9개의 128px PNG는 public/operators에 저장했습니다. 런타임에서 제조사 정밀 도면이 아닌 6개 단순 총기 형태와 양손을 함께 그립니다.
- 무기의 실측 세부 차이, 각 부대의 실제 지급 헬멧/방독면과 개인 복장 고증은 미완료입니다. 공통 표현을 12명 전용 고증 완료라고 부르지 않습니다.
- 검증: tests/minimal-military.cjs 및 validation/minimal-military-roster.png. 작은 몸체 움직임과 사건 기반 반동을 사용합니다. 이 스프라이트는 상세 장전/도약/소생 애니메이션 팩이 아닙니다.

생성 프롬프트는 prompts.json에 보존합니다. 이전 실사 원화들은 폐기 삭제하지 않고 제작 이력으로 남겼습니다.
