# 개발 미리보기 직접 플레이 기록

2026-09-10, Codex 브라우저에서 Replit 개발 미리보기를 직접 조작했습니다.

- 편성: Iron Bisons 대 Azure Owls. 기존 밴픽 화면을 거쳐 실제 경기 진입.
- MAGPIE와 COLLIER의 초상 및 탑다운 원화 표시 확인. 나머지 임시 외형 표시 유지.
- 전체 전황과 선수 확대 전환, COLLIER 선택 후 선수 정보와 초상 전환 확인.
- 일시정지 상태에서 감독의 '각을 잡아라' 명령 대기 표시 확인. 재생 및 4배속 진행.
- 실제 경기 180초 종료, 수비 승리, 공격 4명·수비 4명 생존, 종료 후 명령 비활성화 확인.
- 검사 시 수집된 앱 오류·경고 없음. 브라우저 확장의 메타데이터 오류는 앱 오류와 구분.
- 적용 중 미리보기가 잠시 비어 새로고침 후 다시 시작함. 재시작 원인은 미확인.

## 발견한 표시 오류

기존 index.css의 broadcast-scoreboard, broadcast-team, broadcast-clock 규칙이 신규 관전 스타일과 충돌했습니다. 실제 화면에서 점수판이 기존 6열로 계산됐고 수비 영역 폭이 72px여서 팀명이 잘렸습니다. 중앙 시계에도 기존 right/top 값이 남았습니다. 수정 전 스크린샷에 이 문제가 포함되어 있습니다.

이후 Replit 개발 화면에 스타일 보정이 반영됐고, Crimson Bisons 대 Iron Fangs 경기에서 팀명·인원·시계가 좌우와 중앙에 정상 배치된 것을 다시 확인했습니다. 해동 초상·탑다운 로드 및 선수 확대도 직접 확인했습니다. 최종 이미지: draft-order-live-verified-20260910.jpg, draft-order-zoom-verified-20260910.jpg.

## 원격 소스 확인

GitHub 커밋 83403b3dd1ff451f8f9b51754a83a1aa5108abf1을 직접 조회했습니다. 작성자는 chow0n이며 기존 main 커밋 b9c332c를 부모로 보존합니다. 전달 패치와 변경 파일 해시를 대조한 결과 코드·이미지는 일치하고 검사 결과 파일만 재실행 기록으로 바뀌었습니다. 원격 검사 결과에도 15/15 통과가 저장되어 있습니다. 점수판 추가 수정의 최종 원격 커밋은 별도 확인 대상입니다.

## 범위

이 기록은 개발 미리보기 한 경기의 수동 검증입니다. 공개 배포 갱신, 모든 시드의 AI 품질, 사용자 PC 성능 통과를 의미하지 않습니다. 자동 검사의 실행 결과와는 별개입니다.
