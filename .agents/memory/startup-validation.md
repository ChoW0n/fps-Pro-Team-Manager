name: Startup validation isolation
description: 브라우저 앱 시작 시 무거운 개발 검증을 격리하는 원칙
---

실시간 AI 시즌 검증처럼 오래 걸리고 메모리를 많이 쓰는 개발용 작업은 앱의 기본 import·mount 경로에서 실행하지 않습니다. 사용자가 화면을 먼저 볼 수 있어야 하며, 검증은 명시적인 개발자 요청과 유휴 실행으로 분리합니다.

**Why:** 저사양 개발 환경에서는 초기 JavaScript 실행이 화면 페인트와 같은 메인 스레드를 점유해 앱이 로드되지 않는 것처럼 보입니다.

**How to apply:** 기본 진입에서는 검증 함수와 로그의 import-time 호출을 제거하고, 필요할 때만 validation query 또는 별도 개발 명령으로 동적 로드합니다. 실제 게임 플레이 경로는 검증 분리와 독립적으로 유지합니다.
