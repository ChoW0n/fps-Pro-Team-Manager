## 아직 미구현 — 삭제하거나 완료로 옮기지 말 것

1. 명중 부위와 다운·소생
   - 현재 Bullet은 단일 몸 반경과 damage만 사용하며 머리/몸통 부위가 없다.
   - 헤드샷 즉사, 비치명 부위의 치명 피해 후 다운, 추가 피해·출혈·재다운 처리를 정의하고 실제 탄착 사건에 기록해야 한다.
   - 다운 중 기어서 엄폐 이동 / 정지해 지혈 / 관측 정보 전달. 사격·장전·일반 가젯·설치/해제 금지.
   - 소생자의 접근·거리·시야·위협 평가, 소생 유지 시간, 이동/피격/사망/대상 변화에 따른 취소.
   - 전원 다운과 장치 가동 중 전멸, 운반자 다운, 상호 소생·동시 피격 검사.
   - 레식 최신 규칙·특수 오퍼레이터 예외는 공식 자료 확인 전 동일 구현이라 부르지 않는다. 이번 검색으로 세부 규칙은 검증하지 못했다.
2. 실제 행동 애니메이션 자산
   - 대기·걷기·달리기·조준 이동·앉기/일어서기·포복 전환/이동·회전·사격·장전.
   - 투척·가젯 설치/회수/사용·방패 들기/내리기·브리칭 설치/기폭·틀 넘기·창문 진입.
   - 장치 설치/해제·피격·다운 전환·다운 이동/지혈·소생 수행/받기·사망.
   - 미래 행동은 필요한 자세·중단 조건만 명세하고 가짜 런타임 사건을 만들지 않는다.
   - 현재 정적 스프라이트의 비균등 압축/몸통 흔들기를 위 동작 완성으로 대체하지 않는다.
   - 프레임별 pivot/muzzle, 장비 가림, 발 접지와 이동 거리, 시뮬레이션 행동 시간 동기화가 필요하다.
3. 고증·신규 오퍼레이터
   - 제조사 자료로 총몸·탄창·개머리판·총열·구경 확인. 레식 원화/아이콘/콜사인 복제 금지.
   - 기존 세 명 및 공용 아틀라스 전원 장비/복장 재검토와 스프라이트 재제작 미완료.
   - 신규 오퍼레이터는 창작 고유 가젯·공수·AI 판단·픽·숙련도·저장 호환·아이콘·행동 자산이 함께 연결되어야 완료.
4. 화면 검증

   - 로컬 브라우저 접근이 ERR_BLOCKED_BY_CLIENT로 차단됨. 우회하지 않았다.
   - 수정본 원격 반영 후 짧은 교전, 시야 끊김, 전원 사망, 배속, 세로/가로에서 재검증 필요.
