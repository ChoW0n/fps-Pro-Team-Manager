## 후속 구현 상태 — 코드·검증 근거가 있는 항목만 갱신

1. 명중 부위와 다운·소생 — 1차 엔진·HUD 구현
   - Bullet에 탄착 높이를 기록하고 현재 서기/앉기/포복 자세의 머리·몸통·빗나감을 구분한다. 수평·수직 오차는 동일 시드의 기존 두 난수 표본에서 계산한다.
   - 머리 명중은 즉사, 첫 몸통 치명상은 다운, 추가 치명상·출혈·소생 후 재다운은 사망이다.
   - 다운 중 기어서 엄폐 이동 / 정지 지혈 / 실제 관측 정보 전달. 사격·장전·일반 가젯·설치/해제 금지. 창문/틀 넘기는 금지한다.
   - 소생은 42단위 안에서 4초 정지, 소생 후 체력20. 지혈은 출혈을 늦추지만 멈추지 않는다. 전부 게임용 초기 설정이며 의학·레식 고증값이 아니다.
   - 소생자의 실제 위협 정보·거리·통행 경로를 확인하고 이동/최근 피격/위협/대상 변화에 진행을 취소한다. 관측 수류탄 회피와 임박한 목표 종료를 소생보다 우선한다.
   - 목표 판정에는 다운을 전투불능으로 전달한다. 운반자 다운 시 유실, 전원 다운은 전투 가능한 인원이 없는 것으로 처리한다. 설치된 장치는 기존 목표 규칙을 유지한다.
   - tests/injury-regression.cjs에 부상 단위 검사와 실제 4개 경기 입력·run/session 비교를 저장했다. 다운 원화와 소생 동작 프레임은 아직 없다. HUD/캔버스 구조 표식은 임시 상태 표현이다.
   - 레식 최신 규칙·특수 오퍼레이터 예외는 공식 자료 확인 전 동일 구현이라 부르지 않는다. 이번 검색으로 세부 규칙은 검증하지 못했다.
2. 실제 행동 애니메이션 자산
   - 대기·걷기·달리기·조준 이동·앉기/일어서기·포복 전환/이동·회전·사격·장전.
   - 투척·가젯 설치/회수/사용·방패 들기/내리기·브리칭 설치/기폭·틀 넘기·창문 진입.
   - 장치 설치/해제·피격·다운 전환·다운 이동/지혈·소생 수행/받기·사망.
   - 미래 행동은 필요한 자세·중단 조건만 명세하고 가짜 런타임 사건을 만들지 않는다.
   - 현재 정적 스프라이트의 비균등 압축/몸통 흔들기를 위 동작 완성으로 대체하지 않는다.
   - 프레임별 pivot/muzzle, 장비 가림, 발 접지와 이동 거리, 시뮬레이션 행동 시간 동기화가 필요하다.
3. 고증·신규 오퍼레이터
   - 제조사 자료로 총몸·탄창·개머리판·총열·구경 확인. 레식 원화/아이콘/콜사인 복제 금지.
   - 기존 세 명 및 공용 아틀라스 전원 장비/복장 재검토와 스프라이트 재제작 미완료.
   - 신규 오퍼레이터는 창작 고유 가젯·공수·AI 판단·픽·숙련도·저장 호환·아이콘·행동 자산이 함께 연결되어야 완료.
4. 화면 검증
   - 자동 검사 및 로컬 Skia 렌더는 브라우저 플레이/아이폰 성능 검사가 아니다.
   - 로컬 브라우저 접근이 ERR_BLOCKED_BY_CLIENT로 차단됨. 우회하지 않았다.
   - 수정본 원격 반영 후 짧은 교전, 시야 끊김, 전원 사망, 배속, 세로/가로에서 재검증 필요.
