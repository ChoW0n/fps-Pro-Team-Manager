# 보조무장·방패 상부 원화와 전용 파지 — 2026-09-13

브랜치 `feat/modular-operator-renderer`, PR #15. 시작 HEAD `ea8b87f323afaf78c82aa0ccb4f48419463c6fe6`.
먼저 [ART_APPROVED.md](ART_APPROVED.md)를 읽는다. 승인된 일반 체형·주무기 견착과 C14 자세는 유지한다.

## 구현과 원화

- 글록 17/19, P226, K5, USP, 베레타 92FS, SR-1, MR73를 각각 생성해 8개 상부 PNG로 연결했다. 글록 크기, 92FS 열린 상부, MR73 실린더 실루엣을 구분했다. 특정 생산 세대·실측 치수·12명 복장 고증까지 완료한 자료는 아니다.
- 표시 전장은 16.7~23으로 구분하지만 기존 보조무장 시뮬레이션 발사 원점 `(15,7.5)`는 유지한다. 히트박스·성능·탄약·무기 선택 로직은 변경하지 않는다. 실제 경기의 `weaponName`에 해당하는 원화를 그리며 REUSS의 HK417을 권총으로 임의 교체하지 않는다.
- `equipmentMountPose`가 의식 있는 포복에서 몸통 투영에 맞춘 어깨와 양손·총기 접점을 계산한다. 총기 자체에는 늘이기/찌그러뜨리기를 적용하지 않는다. 포복 하체가 몸통 아래까지 이어지도록 틈을 보완했다. 다운/사망은 사격 포복과 구분한다.
- 휴대 방패는 실제 생성 PNG의 뒤쪽 손잡이를 지지손에 고정한다. 총기는 방패 옆으로 이동하고 표시 총구도 같은 장착 좌표를 따른다. 설치형 방패는 기존 엄폐물 위치에 등비 축소하며 충돌 크기를 바꾸지 않는다.
- 방패를 든 동안에는 지지손을 손잡이에 유지한다. 방패를 내리고 장전·투척하는 별도 전환, 포복 추진 보행, 볼트 조작·탄창 분리 애니메이션은 이번 파지 작업에 포함하지 않는다.

## 반복 실패 후 처리 방식

USP 투명 배경 편집이 두 번 체크무늬 RGB로 나왔다. 사용자가 코드 후처리 방식 전환과 규칙 갱신을 명시적으로 승인했다. 이후 새 원화는 단색 마젠타로 생성하고 `scripts/art/prepare_sprite.py`로 배경 분리·여백·등비 축소를 수행했다. USP에만 어두운 연결 실루엣/내부 밝은 디테일 보존 모드를 사용한다.

`art-source/sidearms-top/`에 생성 프롬프트, 원본 PNG 해시, 디코딩 픽셀 동일성을 확인한 무손실 WebP 원본, 처리 로그를 보존했다. 원본 RGB는 마스크 단계에서 유지하고 최종 축소는 Lanczos를 사용한다. 원본 PNG는 생성 결과에도 남아 있다. 재현: `python scripts/art/verify_equipment.py`.

개인 `game-art-reference` 스킬에도 원인별 수정 1회 후 반복 중단, 허용된 코드 처리 전환, 원본 보존·실제 알파·밝고 어두운 배경 검수 규칙을 추가하고 원격 반영을 확인했다. 상위 도구 규칙이나 승인 계약을 완화하지 않는다.
