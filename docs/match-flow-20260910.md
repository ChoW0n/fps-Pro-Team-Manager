# 다중 라운드와 공수 교대

기존 통합본은 Replit이 실제 앱에 적용·검사하고 main `9552648c4f8dc812fe7430b6d860e4beb7864e77`에 일반 푸시했습니다. GitHub 원격 커밋을 직접 확인했고, 로컬 통합본 `992838c`와 실제 게임 소스가 일치합니다. 차이는 재실행한 검증 보고와 정적 렌더 파일입니다.

이번 후속 변경은 기존 시작 경로에 여러 라운드를 연결합니다. 7승 선착, 6라운드 후 공수 교대, 6:6에서는 공수를 매 라운드 교대하며 8승 선착으로 끝납니다. 프로젝트 자체 규칙이며 최신 실존 대회 규정을 검증했다는 뜻은 아닙니다. 무승부는 승점과 공수를 유지한 재경기입니다.

실시간 세션이 반환한 결과만 고정 홈·원정 팀 점수에 반영합니다. 종료 알림 중복은 시도 번호로 막습니다. 라운드 사이에 오퍼레이터를 다시 편성하고, 공수에 맞는 실제 습득 목록만 사용합니다. 수비 시 감독 지시는 내 수비팀에 전달되고 공격 진입 방향 명령은 숨깁니다. 팀 탭을 잠깐 벗어나도 진행 화면이 유지됩니다.

경기 생성 때만 새 기본 시드를 만들고 이후 각 라운드 시드는 이력으로 결정합니다. 같은 기본 시드·이력·편성·명령 틱은 같은 엔진 입력을 만듭니다. 새 세션은 체력·탄약·생존·목표·작전 상태를 새로 시작합니다. 라운드 중 리스폰을 추가하지 않습니다.

검증: 기존 49개와 신규 7개, 합계 56개 검사/장면 통과. 신규 검사는 점수의 팀 귀속, 정규 종료, 연장 교대, 무승부 재경기, 중복 종료 방지, 결정론, 교대 후 실제 엔진 입력과 초기 상태를 확인합니다. 타입 검사와 Vite 빌드 통과(119 modules, main JS gzip 114.65 kB). 새 런타임 의존성 없음.

제한: 현재 클라우드 브라우저 정책이 개발 미리보기 주소를 차단하여 이번 UI 직접 클릭·전체 매치 플레이는 확인하지 못했습니다. 자동 검사와 브라우저 검증은 다릅니다. 수비 초기 전술 세부 설정, 상대 공격 작전 다양화, 라운드간 수동 픽 보존, 경기 저장·복원, 특수 장비 효과, 추가 원화·연속 애니메이션, 전체 시즌 호환 정리는 남아 있습니다. 수비 때 상대는 기존 기본 북쪽/A 즉시 진입을 사용합니다.
