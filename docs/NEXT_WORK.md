# 다음 작업 — 관전 한 라운드 실기기 검수

## 바로 시작할 요청

> 준비→교전→설치→종료 단계 HUD가 반영된 모바일 가로 화면에서 한 라운드를 관전하고, 3초 안에 팀·시간·생존 인원·현재 단계를 읽을 수 있는지 확인해 주세요. 겹침이나 오표시가 있으면 기기·해상도·단계·스크린샷을 남기세요.

## 완료 조건

- 준비·교전·설치·종료가 실제 상태보다 먼저 표시되지 않는다.
- 팀명·라운드 시간·양 팀 생존 숫자·현재 단계를 3초 안에 판독한다.
- 설치 시작, 장치 가동, 무력화 중 진행 문구가 목표 상태와 일치한다.
- 가로 화면에서 단계 HUD가 킬 피드·목표 HUD·점수판과 겹치지 않는다.
- iOS Safari와 Android Chrome 결과를 코드 계약 검증과 구분해 기록한다.

## 범위 밖

체형/총기 재제작, 새 맵, 대규모 리팩터링, 전체 UI 교체, 모델 로그인 재시도는 병행하지 않는다.

## 후속 순서

| 순서 | 티켓 | 입력 | 완료 기준 |
|---|---|---|---|
| 1 | 한 라운드 관전 실기기 검수 | 현재 모바일 중계 화면 | 준비/교전/설치/종료 3초 판독 |
| 2 | 음향·장비 | QA 원문, 실기기 피드백 | 무기군·거리·실내외 식별 검수 |
