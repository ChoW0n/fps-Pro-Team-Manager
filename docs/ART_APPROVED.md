# 캐릭터 아트 기준 — Survivor 원본 우선

사용자의 2026-09-13 최종 지시: “원본 형태 인체비가 제일 적절하다.” 이 지시는 과거 코드 도형 아트 승인을 대체한다. 이번 결과를 원본 애니메이션의 완전 복제로 표현하지 않는다.

- 머리·몸통·배낭 PNG의 원본 종횡비를 유지한다. 총기 때문에 인체를 길게 늘이거나 몸통을 비틀지 않는다.
- 팔 소매의 폭·겹침을 유지하고, 총기 장착점과 손을 맞춘다. 필요하면 총기 표시 규격부터 고친다.
- 배낭 옆 팀색 막대와 군장 색상 막대는 제거했다. 팀 식별은 기존 관전 링·이름·HUD를 사용한다.
- 서기·앉기, 방패+보조무장만 유지한다. 포복과 방패+주무장을 재도입하지 않는다.
- 모델 변경이나 새 채팅만으로 체형을 다시 설계하지 않는다.
