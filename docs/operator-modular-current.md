# 조립식 오퍼레이터 렌더링 — 2026-09-13

최신 사용자 결정에 따라 총기 포함 통짜 인물 시트를 활성 중계 경로에서 제외했다. 기존 WebP와 메타데이터는 제작 이력으로 보존하지만 새 캐릭터의 기준이나 런타임 폴백으로 사용하지 않는다.

## 디자인 원칙

“오퍼레이터의 외형과 성능은 연결되지 않는다.” 외형은 역할을 암시하거나 능력치를 보정하지 않는다. 큰 체격·두꺼운 군장·긴 총·밝은 색·특수 장비의 모양은 이동 속도, 충돌 반경, 체력, 조준, 반동, 피해량에 관여하지 않는다. 성능은 기존 시뮬레이션 데이터에만 있고 조립 모듈은 읽기 전용 `RealtimeUnitState`와 무기 표시 앵커만 사용한다.

## 레이어 계약

| 순서 | 레이어 | 회전·동작 | 해결하는 문제 |
|---:|---|---|---|
| 1 | 그림자 | 월드 고정 | 바닥 접촉과 높이 인지 |
| 2 | 다리·골반 | 이동 방향, 보행·앉기·포복 | 조준 방향으로 미끄러지는 발 제거 |
| 3 | 몸통 | 조준 방향 | 하체와 독립된 상체 트래킹 |
| 4 | 위팔·아래팔 | 고정 길이 2관절 | 총에 맞춰 팔을 늘이는 왜곡 방지 |
| 5 | 총기 | 원본 PNG, 균일 축척 | 총기 실루엣과 세부 보존 |
| 6 | 손·장갑 | 총기 앵커 위 | 손과 총 사이의 빈 공간 제거 |
| 7 | 머리·헬멧·군장 | 상체 방향 | 오퍼레이터 식별과 자연스러운 가림 |
| 8 | 팀 표식 | 상체 바깥 | 복장색과 진영 정보 분리 |

총기가 자세의 기준물이다. 모든 총기는 `개머리판 / 방아쇠손 / 지지손 / 탄창 / 총구` 앵커를 갖고, 손이 그 좌표에 붙는다. 총기 이미지를 팔에 맞춰 늘이거나 기울이지 않는다.

## 현재 구현

- `components/modularOperator.ts`가 레이어 순서, 하체/상체 방향, 무기 자세군, 고정 길이 팔, 장전·투척·설치 손 위치를 한 인터페이스 뒤에서 계산한다.
- `BroadcastCanvas.tsx`는 더 이상 `operatorStateVisual`이나 `drawOperatorSheet`를 호출하지 않는다. 살아 있는 선수의 총구 표시는 표시용 견착/반동 좌표를 사용하며 시뮬레이션 원점은 유지한다.
- 기존 `minimalOperator.ts`의 호출 이름은 호환용 재수출만 남고 실제 인물 구현은 조립 모듈 하나다.
- 현재 총기 레이어는 기존 투명 탑뷰 PNG 12종을 사용한다. 하체·몸통·팔·손·머리·군장은 구조 검증용 Canvas 도형이며 최종 원화가 아니다.

## 다음 원화 제작 규격

한 오퍼레이터를 먼저 제작한다. 모든 파츠는 같은 투명 캔버스, 같은 골반 원점, 오른쪽을 향하는 기준 방향을 공유한다.

- 하체: 서기 통과 1, 걷기 4, 앉기 이동 4, 포복 2프레임. 발과 골반만 포함한다.
- 몸통: 복장과 플레이트 캐리어. 팔·손·총·가젯을 포함하지 않는다.
- 머리·군장: 헬멧/머리와 등·허리 장비를 필요하면 별도 파츠로 나눈다.
- 팔: 위팔과 아래팔을 각각 분리하고 어깨·팔꿈치·손목 앵커를 기록한다. 관절 끝에는 겹침 여유를 둔다.
- 손: 방아쇠손, 지지손, 권총 양손, 작업손. 총기나 팔을 이미지 안에 합치지 않는다.
- 총기: 현재 원본을 보존하고 다섯 앵커를 메타데이터에 둔다. 광학장비·탄창 분리가 필요한 장전만 후속 파츠로 만든다.
- 이펙트: 총구 화염, 탄피, 피격, 먼지, 연막은 캐릭터 파츠에 굽지 않고 사건 레이어로 유지한다.

첫 승인 묶음은 MAGPIE 한 명과 L119A2, X95, P90, HK417, C14 다섯 자세다. 이 묶음에서 64px/128px 식별, 손 접촉, 하체/상체 분리, 장전·투척을 승인한 뒤 12명으로 확장한다.

## 검증과 한계

`tests/modular-operator-contract.cjs`는 12개 주무기의 앵커 순서, 손 접촉, 고정 팔 길이, 6개 자세군, 하체/상체 방향 분리, 외형/성능 데이터 격리를 검사한다. `tests/render-broadcast-canvas.cjs`는 16개 화면 조건에서 통짜 시트 없이 조립 총기 레이어가 실제로 그려지는지 확인한다.

로컬 Canvas와 타입 검사는 실제 브라우저·모바일 플레이 승인이나 최종 인체 원화 승인이 아니다. 최종 파츠 원화와 권총·방패 전용 연출은 미완료다.
