# 캐릭터 축척·견착 위치와 다운 후 문 예약 — 2026-09-13

사용자 요청: 레식의 맵 대비 오퍼레이터 비율을 참고해 과도한 몸통·군장 두께와 겨드랑이에 낀 듯한 총기 위치를 수정하고, 남은 AI 통행 작업을 계속한다.

## 반영

- 몸체 로컬 좌표를 전후 0.8, 좌우 0.7배로 조정했다. 헬멧·배낭·파우치도 같은 몸 좌표계를 사용한다. 실제 Canvas의 불투명 실루엣 폭은 12명 모두 22~25단위다. 40단위/m 기준 0.55~0.625m이며, 맵의 96단위 문폭 대비 22.9~26.0%다. 총기 원화와 전장 지도에는 몸체 축척을 적용하지 않았다.
- 오른쪽 개머리판을 로컬 (-8,15)에서 (-3,7.5)로 옮겨 어깨 안쪽에 놓았다. 엔진 총구와 렌더러는 같은 좌표 함수를 사용한다. 발사 원점이 바뀌므로 경기 결과도 달라질 수 있다. 총기 전장·탄퍼짐·피격 반경·이동 충돌 반경은 변경하지 않았다.
- 몸 그림자 19×15→15×11, 기본 선택 고리 반경 20→16. 멀리서 선택할 수 있도록 기존 최소 화면 크기 규칙은 보존했다.
- 다운된 선수의 문 예약을 해제한다. 살아 있는 다운 상태를 예약 해제 조건에서 빠뜨린 결함이었다. 별도 몸 충돌은 유지하며, 다운된 몸이 문 안에 있을 때도 겹쳐 지나가지 않는다.

레퍼런스: Ubisoft의 [Rook 소개와 게임 이미지](https://www.ubisoft.com/en-us/game/rainbow-six/siege/game-info/operators/rook). 원근이 있는 장면에서 견착 위치와 문 대비 실루엣을 시각적으로 참고했다. 위 수치는 본 게임에서 정한 값이며 레식의 공식 실측값이 아니다. 기존 절차적 캐릭터의 비율 수정이며 완성형 자세 원화·팔/손 애니메이션 제작 완료를 뜻하지 않는다. 분리된 장갑 점만 추가하는 시도는 정적 렌더에서 떠 보이므로 채택하지 않았다.
