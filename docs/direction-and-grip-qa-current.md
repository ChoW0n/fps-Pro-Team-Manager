# 방향·총기 파지 QA — 반영 상태

2026-09-12 첨부 QA를 현재 코드와 대조해 반영했다. 원문은 업로드 보관본으로 유지하며 이 문서는 현재 구현과 검증 근거다.

## 방향: 사전 결정형

경기 중 `진입·대기·후퇴·경로 변경` 지시는 제거했다. 중계에는 층 선택, 자동/전술 시점, 일시 정지, 배속과 선수 선택만 남긴다.

준비 화면은 다음 세 축으로 축소했다.

| 축 | 선택 | 실제 입력 |
|---|---|---|
| 방향 | 남산의 외부·상층 진입 경로 | `entryRoute`, 해당 경로의 A/B 우선 사이트 |
| 교전 태도 | 교차 엄호 / 차단 후 진입 / 변수 만들기 또는 수비 태도 | `attackStyle` / `defenseStyle` |
| 정보 우선순위 | 즉시 진입 / 1명 25초 확인 / 2명 40초 확인 | `scoutPlan`; 수비는 카메라·해치 보강·방패 준비 |

선수 수동 편성, 선수별 숫자, 별동조, 마지막 사이트 진입, 보강 좌표 선택은 준비 화면에서 제거하고 자동 편성·결정으로 처리한다. 경기 뒤에는 실제 사건을 복기한다.

`tests/preparation-choice-balance.cjs`는 고정 북측 진입로·8시드에서 세 정보 선택×세 공격 태도 72경기를 실행했다. 모든 조합이 실제 재진입했고 8경기 중 7~8회 공격 승리를 기록했다. 표본의 최대 차이는 12.5%p다. 이는 전체 맵·모집단의 밸런스 증명이 아니다.

## 총기 파지

`muzzlePosition`은 더 이상 오퍼레이터 측면 원화의 픽셀 앵커를 읽지 않는다. 새 탑뷰 총기 PNG의 길이와 오른어깨 로컬 오프셋을 기준으로 계산해 엔진 발사 원점과 렌더러가 같은 값을 사용한다.

- 총 중심선: 몸 중심에서 오른어깨 쪽 `y=7`
- 개머리판: 몸 뒤쪽 `x=-16`에서 멈춤
- 팔: 상완 9·전완 8의 두 관절 기하로 손 위치에 연결
- 손: 반지름 4×3.3으로 확대

`tests/weapon-grip-contract.cjs`가 12종에서 어깨 오프셋, 개머리판, 양손 위치와 8방향 회전 원점을 검사한다. `tests/weapon-presentation.cjs`는 12종×8방향 PNG 조립과 회전 연속성을 검사한다. 원화의 제조사 고증이나 실제 기기 플레이를 보증하지 않는다.

## 검증

- 총기 파지 계약, 12종×8방향 원화, 오퍼레이터 행동·자산 계약 통과
- `realtime-regression`, `combat-overhaul`, `tactical-counters`, `vertical-combat` 통과
- 20경기 전투 감사: 평균 65.4초, 명중 중 머리 8.37%, 한 선수 최다 처치 4회. 첨부 QA의 9초 전멸 장면은 이 고정 표본에서 재현되지 않았고, 장기 모집단 검증이 남아 있다.
- Vite 프로덕션 빌드 통과
- 브라우저에서 준비 버튼을 눌러 경기까지 진입하는 직접 검증은 아직 남아 있다.
