# 선수 AI 보는 재미 — Phase A~F 구현 기록

기준: `fix/qa-complete-coverage`, 원격 기준 `2576ea4`. 전달받은 `spec-ai-behavior-fun-first.md`의 Phase A부터 F까지 구현한 기록이다. 브라우저 검증은 사용자 결정에 따라 Codex가 수행하지 않으며 사용자·Claude 검증 대상으로 남긴다.

## 실제 구현

### Phase A — 교전 지속

- 근거리 표적 획득 항과 이동 직후 정착 부족 탄퍼짐을 적용했다. 공격 승률 하락 조건에 따라 근거리 계수는 명세의 `.28`을 사용한다.
- 표적 식별 시간과 총구 정착 시간이 동시에 끝난 것으로 세지 않고, 식별 뒤 조준 유지 시간을 첫 탄 정착값으로 사용한다.
- 이동 충돌 반경 12와 피격 실루엣 반경 5.8을 분리했다. 방위·높이 난수를 독립시켜 중앙에 몰리던 삼각분포를 제거했고, 수직 편차는 화면상 신체 높이 축에 맞춰 0.6배로 환산한다.
- 의도적 머리 조준은 제어 0.95 초과·1.2초 이상 안정 상태만 허용한다. 나머지 머리 명중은 탄도 편차 결과다.
- 오퍼레이터 속도는 44/52/62, HP는 125/100/80의 세 등급이며 선수 `teamSynergy/20`은 유지한다.

### Phase B — 판단 표현

- 진입·엄호·후퇴·압박·장거리 우회·소리·로머·앵커·가젯·장전·구조를 포함한 실제 분기에 `decision`을 연결했다.
- 선수 카드와 독립된 하단 최근 3개 판단 피드를 유지한다. 같은 선수의 같은 판단은 연속으로 다시 쌓지 않으며 전술 보기에서 숨기지 않는다.

### Phase C — 진입 대형

- 생존자의 `formationIndex`로 `point / follow / cover`를 매 틱 재배정한다.
- 후속은 선두 뒤 90단위·좌우 ±45, 엄호는 180단위·좌우 ±70을 기준으로 이동하고 엄호는 선두 반대 방향을 본다.
- 선두는 문과 실제 경로 모서리에서 한 지점당 한 번, 0.6초 각을 확인한다.
- 후속 사격은 선두가 조준·사격·피압박·최근 직접 접촉 중일 때만 열린다.
- 대형 추종은 `operation.phase === entering`이면서 준비 경로를 끝내기 전까지만 적용한다. 복귀·합류·내부 목표 수행을 덮어쓰지 않는다.

### Phase D — 정보 반응

- 적을 직접 보지 못한 상태에서 최신 적 소리를 들으면 이동 목표는 유지하고 몸과 조준을 소리 방향으로 선회한다.
- 동료 사망 위치를 12초간 위험 지점으로 공유한다. 반경 160 안에서는 crouch, 경로 노드는 +40 비용을 사용한다. 위험 반경을 나갔다 다시 들어오면 새 발동으로 기록한다.
- 공격은 건물 진입 전, 신뢰도 0.6 초과 시 반대편 접근점을 라운드 전체 한 번만 다시 선택한다.
- 다운 유닛의 이탈 목적지를 최초 한 번 고정해 매 틱 반대 엄폐를 재선택하던 방향 반전을 제거했다.
- 충돌 대기 시간이 실제 이동에도 적용되며, 장치 운반자는 설치점 접근 중 주변 지원자보다 통행 우선권을 갖는다.

### Phase E — 규칙 표

- 중앙 행동 캐스케이드를 `unitActionRules.ts`의 순서가 있는 13개 규칙으로 추출했다.
- 추출 직후 Phase F 적용 전, 시드 3/17/41/89의 전체 events·snapshots SHA-256이 전후 완전히 같았다. 기록은 `validation/unit-action-rule-equivalence.json`에 있다.

### Phase F — 월뱅과 재장전

- 팀의 최근 시각 보고가 3초 안이고 비보강 연질 내벽 정확히 한 장 뒤일 때만 월뱅한다. 피해 55%, cone 1.6배, 머리 판정 제외, 라운드 최대 4발이다.
- 잔탄 30% 이하 전술 재장전은 본인 시야·알려진 위협·압박뿐 아니라 적의 실제 역방향 관측에도 노출되지 않을 때만 시작한다. 빈 탄창 강제 장전은 별도 규칙이다.

## 자동 회귀와 외부 검증 경계

- 과거 기준 14개 스위트와 새 `fun-first-ai`, `unit-action-rules`를 실행했다. 월뱅 도입으로 깨진 구형 직사 가정은 일반 사격과 연질벽 월뱅 계약으로 분리했다.
- 타입 검사와 프로덕션 빌드는 별도로 실행한다.
- Codex는 브라우저·Playwright·화면 캡처·청음을 하지 않는다. 사용자·Claude는 Replit 반영본에서 대형, 코너 정지, 소리 선회, 위험 지점 crouch, 하단 판단 피드와 실제 플레이 밸런스를 확인한다.
