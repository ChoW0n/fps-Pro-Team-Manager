# 실제 편성·선발조 후속 연결

기준 원격은 `8fba9f5`, 이전 로컬 체크포인트는 `3ce3e75`입니다. `bomb-ai-update-20260910.md`의 당시 미완료 항목 중 오퍼레이터 편성과 선발조를 이번 변경에서 연결했습니다.

## 경기 경로

팀 검토 → 선수별 오퍼레이터 편성 → 선발조·진입 방향·A/B 목표 설정 → 기존 실시간 관전으로 연결됩니다. Home의 실제 시작 경로에서 14단계 챔피언 밴픽과 장비 점수 환산을 제거했습니다. 과거 MOBA 코드·도감·기록 호환 모듈의 전면 삭제나 저장 데이터 마이그레이션은 하지 않았습니다.

편성은 선수의 실제 습득 목록, 공수, 다섯 명 명단, 팀 내 중복을 검사합니다. 수동 픽을 보존하고 나머지는 제약이 많은 선수부터 역추적하여 자동 배정합니다. 불가능한 기존 명단에 미습득 오퍼레이터를 몰래 추가하지 않습니다. 새 선수 생성에만 기본 공격·수비 오퍼레이터를 한 명씩 부여해 새 5인 팀이 양쪽 편성을 만들 수 있게 했습니다. 오퍼레이터 설정·무기는 변경하지 않았습니다. 오퍼레이터별 개별 숙련도 저장 모델은 아직 없으며 기존 선수의 단일 숙련도와 혼동하지 않습니다.

선발조는 0~3명, 수색 시간은 25/40/55/70초입니다. 0명은 즉시 진입합니다. 선택된 선수는 지정 방향을 확인하고 시간이 끝나면 자신의 합류 위치까지 실제로 걸어 돌아옵니다. 진압조도 합류 위치에 도착했는지 확인한 뒤 함께 재진입합니다. 전사자는 합류 조건에서 제외합니다. 작전 국면은 개인의 사격·장전·후퇴 행동과 별도로 유지됩니다. 복귀 시간을 고정 20초로 순간이동시키지 않습니다.

선택한 사이트를 무시하고 A까지 먼저 방문하던 기본 경로도 수정했습니다. 지정 출입구로 들어온 뒤 실제 선택한 A/B 목표로 진행합니다. 다른 메뉴를 열 때 현재 관전을 해제하지 않아 탭 복귀로 경기가 초기화되지 않습니다.

## 실제 집단 입력에서 추가로 찾은 문제

두 명의 문 통과만으로는 다섯 명의 이동을 보장하지 못했습니다. 준비 화면과 같은 한 방향 5인 진입·선발조 2인 입력에서 다음 세 문제를 재현해 고쳤습니다.

1. 뒤쪽 선수가 문 예약을 소유한 채 앞사람을 막음 → 같은 방향의 앞선 선수에게 예약을 넘깁니다.
2. 수색·교전으로 지나친 입구 경유점으로 역행 → 이동 경로에서 이미 지나친 점을 건너뜁니다.
3. 엄호 담당자가 설치 지점을 점유해 운반자가 설치하지 못함 → 설치와 엄호 위치를 분리합니다.

한 방향 즉시 진입 8개 고정 시드에서 방향 반전은 9~18회, 통로 대기 사건은 100~146회였습니다. 선발조 2명·40초 후 합류 8개 시드에서는 반전 5~13회, 대기 사건 96~118회였습니다. 수정 전 같은 입력의 대기 사건은 즉시 진입 313~1888회, 선발조 891~897회였습니다. 대기 사건 수는 정당한 줄서기도 포함하므로 0을 목표로 삼지 않습니다. 두 입력 모두 8개 시드에서 공격이 승리했으며, 이는 밸런스 검증 통과를 뜻하지 않습니다. 복수 진입 경로·선수 능력치·오퍼레이터 조합을 포괄하는 튜닝은 남아 있습니다.

## 검증 구분

- 목표 규칙 17개, 실제 엔진 회귀 19개, 편성·선발조 12개, 별도 좁은 문 양방향 통과 장면 1개를 저장했습니다. 합계 49개 검사/장면이며 실제 앱 49경기 플레이가 아닙니다.
- 선발조 검사에는 실제 이동으로 복귀·합류·재진입, 이동 선분 충돌, 순간이동 부재, 동일 입력의 run/session 결과 동일성을 포함합니다.
- 설치 검사는 다섯 공격수와 원거리 수비수를 배치해 동료의 엄호 이동과 실제 설치를 함께 검사합니다.
- 타입 검사·Vite 빌드, 숨은 능력치가 새 UI에 원시 숫자로 노출되지 않는지 소스 점검을 수행했습니다. 새 런타임 의존성은 없습니다.
- `render-tactical-review.cjs`는 실제 엔진 스냅샷을 실제 SVG 컴포넌트로 렌더합니다. 선택적 PNG 변환은 로컬 검토용 ImageMagick/Inkscape를 사용하며 게임 런타임 의존성이 아닙니다. 로컬 래스터 환경에 한글 폰트가 없어 이 PNG로 한글 배치·브라우저 글꼴을 검증하지 않습니다. React 제목 경고는 문자열로 합쳐 수정했습니다.

새 버전의 Replit 반영·실제 브라우저 조작·공개 배포는 미확인입니다. GitHub 읽기와 최신 main 가져오기는 성공했지만 이 실행 환경의 push는 `could not read Username for https://github.com`으로 실패했습니다. Replit 토큰을 추출하지 않았습니다. 작업공간 브라우저는 보안 확인 화면에서 중단했습니다. 추가 Replit Agent 개발 요청은 보내지 않았습니다.

다중 라운드·공수 교대, 오퍼레이터별 특수 장비의 실제 전투 행동, 세 명 외 고유 원화, 이동·장전·사망 연속 프레임, 전체 도감·기록의 MOBA 호환 제거, 저사양 사용자 PC 성능 측정은 미완료입니다.
