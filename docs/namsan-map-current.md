# 남산 중계관 — 현재 맵 작업

## 목표와 적용 범위

2026-09-12 사용자가 기존 맵을 삭제하고 한국 랜드마크를 모티브로 다시 만들도록 지시했다. 과거의 “연구동 외곽 셸 유지”는 대체한다. 기존 자료는 Git 이력으로 보존하며 활성 지도는 남산 중계관 하나다. 실제 남산타워 평면이 아닌 가상 관광·방송 시설의 **1층 전술 블록아웃**이다. 랜드마크 외관 원화나 층간 시스템 완성을 뜻하지 않는다.

## 실제 변경

- 실내 24×24m, 16개 방. 매표·기념품·카페·전망, 안내·송출·관제·전시, 정비·전원·배전·자료, 반입·휴게·준비·테라스.
- 방은 5×6m 또는 7×6m. 문 위치를 엇갈리게 배치하고 가구로 사선을 나눈다. 관광·방송·설비 구역 색상과 1F 콜아웃을 공통 렌더러에 반영했다.
- 5개 외부 진입, 그중 창문·넘기·저상 통로를 실제 통과 판정과 연결했다. 저상 통로 2개는 수직 해치가 아니다.
- A=송출/관제, B=전원/배전. 각 방에 설치 지점을 두고 AI가 자기 진입 방향에 가까운 방을 선택한다. 비공개 적 위치는 사용하지 않는다.
- 옛 맵 좌표에 고정된 테스트를 새 지형으로 이전했다. 접촉 검사의 준비 입력이 의도한 시작 배치를 덮던 문제도 바로잡았다. 사건 발생·통행·결정론 조건은 유지했다.
- 넓힌 스폰 차폐 안에서 합류 통행을 확인했다. 구조 접근 중 모서리 위협이 드러나면 즉시 중단하고 안전이 0.8초 유지된 후 재시도해 매 틱 전진/복귀 반전을 막았다.

## 검증 결과

`node tests/map-contract.cjs`는 지도 이름·방 메타데이터뿐 아니라 실제 기하와 틱 실행을 검사한다.

| 항목 | 최종 측정 |
|---|---:|
| 실내 면적 | 576㎡ |
| 방 크기 | 30㎡ / 42㎡, 8m 초과 0개 |
| 실내 표본 | 1m 격자 368지점, 모든 지점 쌍 검사 |
| 열린 사선 쌍 | 9,846 |
| 표본 최장 사선 | 24.083m |
| 25m 초과 사선 | 0개 |
| 스폰→실내 표본 사선 | 0개 |
| A 실제 스폰→선택 설치점 경로 편차 | 10.31% |
| B 실제 스폰→선택 설치점 경로 편차 | 16.85% |
| 실제 설치 | A/B 네 방 각각 7초 설치 성공 |
| 실내 독립 연결 | 2개 |

사선 수치는 연속 공간의 수학적 상한 증명이 아니다. 기존 간격 추출 감사의 21.26m와 전수 표본 감사의 24.083m는 분모가 다르다. 거리 편차는 **사이트별 실제 몸 반경 경로 길이**로 계산했다. 직선 거리는 불균등하며 경로 길이와 혼동하지 않는다. 이동 시간에는 문 통과와 교전 차이가 추가되므로 별도 밸런스 검증이 필요하다.

고정 편성·UI 선발조 입력·5진입로×2시드의 최종 10경기는 공격 5승, 대기 순환 감지 1틱, 최장 연속 대기 2.9초, 대기 유닛 틱 1,455였다. 승률 보정은 하지 않았으며 10경기로 전체 밸런스를 보장하지 않는다.

원시 근거: `validation/namsan-map-contract.json`, `validation/namsan-level-design.json`, `validation/namsan-suites.json`, `validation/namsan-ai-audit.json`. 타입 검사와 프로덕션 빌드 통과. 15개 기존 스위트 모두 통과했고 최종 결과 JSON에 남겼다. 최종 스폰 1개 조정 후에는 영향받는 4개 스위트와 지도 계약·배치를 다시 검사했다.

`validation/namsan-map-review.png`는 게임의 공통 Canvas 지도 렌더러를 Skia에서 실행한 정적 출력이며 브라우저 플레이 캡처가 아니다. 재생성은 `REVIEW_FONT`에 한글 글꼴 경로를 지정하고 `node tests/render-map-review.cjs`를 실행한다. 검토 출력은 Google Fonts의 Noto Sans KR로 확인했다.

## 아직 미완료

- 2층, 두 계단, 수직 해치, 층별 관측/이동 차단과 층간 사격.

- 랜드마크 실루엣·고유 가구·주변 산책로 등 최종 아트. 현재 반복 가구는 전술 블록아웃이다.
- 연속 공간/다양한 선수 모집단에서의 밸런스와 브라우저 경기 진입 실검증.
