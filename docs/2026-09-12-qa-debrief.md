## P1 — 불쾌한 골짜기 (시각·표현)

가장 큰 원인은 아트 품질이 아니라 **투영 방식의 불일치**다. 지면·벽·가구는 완전한 탑다운인데 인물은 정면 입상으로 그려진다.

### P1-04 탑뷰 맵 위에 측면뷰 캐릭터가 서 있다 `[화면]` `[코드]`

`src/components/minimalOperator.ts`의 몸체 폴리곤은 머리 `y -38`부터 부츠 `y +22`까지 세로 60단위를 차지하는 정면 입상이다. 40단위 = 1m이므로 사람 한 명이 바닥 깊이 1.5m를 덮는다. 같은 화면의 선반·책상·트럭은 위에서 내려다본 그림이다.

방향도 네 상태뿐이다.

```ts
export function operatorDirection(facing:number) {
  return Math.abs(Math.sin(facing))>.72 ? {view:Math.sin(facing)>0?'front':'back',mirror:1}
                                        : {view:'side',mirror:Math.cos(facing)<0?-1:1};
}
```

`front / back / side` + 좌우 반전. 총기는 360° 연속 회전하므로 대각선을 보는 선수는 몸은 정측면인데 총구만 비스듬히 나간다.

화면 확인: 라운드 25초 A 사이트 안의 다섯 명이 모두 정면·측면을 보고 서 있는 반면 책상·선반은 탑다운. 4배 확대 시 세 명 모두 동일 몸체 템플릿·동일 포즈.

**수정 방향(선택 필요)**
1. 인물을 진짜 탑다운(머리·어깨 중심)으로 다시 그리고 총기 회전을 360° 연속으로 둔다. 지형 아트는 그대로.
2. 45° 비스듬한 뷰로 통일하고 벽·가구·바닥까지 같은 각도로 다시 그린다. 작업량이 크다.

어느 쪽이든 P1-05·P1-08·P1-12가 같이 해결된다.

벽 모서리 각도에 광선을 추가하지 않으므로, 한 광선은 벽에 막히고 인접 광선은 문틈을 통과할 때 두 끝점을 잇는 직선이 벽을 가로지른다. **판정 로직 자체는 정상**이며 표시용 샘플링만의 문제다.

**수정 방향**: 각 벽 끝점 각도(±ε)를 광선 목록에 추가하고 각도순으로 정렬한다.

### P1-14 맵이 실내 공간으로 읽히지 않는다 `[화면]` `[코드]`

거의 동일한 직사각형 방 여덟 개와 중앙 홀, 방마다 같은 선반 사각형 한두 개. 복도·문 개구부·진입 각이 시각적으로 구분되지 않아 격자표처럼 보인다. 기존 백로그 항목이지만 실제 화면으로 확인했으므로 상태를 확정해 둔다.
