# 승인 외형 유지 · 기본 동작 전환 — 2026-09-13

기준: `feat/modular-operator-renderer`, PR #15, 시작 HEAD `ed403e598966bf259ceb2cf520188d86c400fdf8`.
외형 정본: [ART_APPROVED.md](ART_APPROVED.md)의 `36c72b7`. 이번 작업은 새 동작의 사용자 미술 승인이나 병합·배포가 아니다.

## 구현

- `modularOperator.ts`의 `OperatorAnimator`가 선수별 표시 상태만 소유한다. `BroadcastCanvas.tsx`가 보간된 선수 상태와 경기 시각을 전달한다.
- 실제 이동 거리 24단위마다 보행 한 주기, 기존 진폭 1.4를 유지한다. 좌표가 이동하지 않으면 속도 값만으로 제자리 걷기를 만들지 않는다. 시작·재시작의 변화량을 제한하고 정지 시 0.12초 이내 중립으로 돌아온다.
- 하체 방향은 초당 최대 8라디안으로 복귀한다. 이동 방향이 조준에서 110도를 넘으면 후진 축을 선택한다. 상체·총기는 실제 facing을 따른다.
- 서기 하체 X=-10, 앉기 X=-7 사이를 0.18초에 전환한다. 승인된 머리·몸통·군장·총기 비율과 레이어는 바꾸지 않는다.
- 정지 전환 시 돌아간 다리 끝이 헬멧 뒤로 솟는 중간 프레임을 정적 검수에서 발견했다. 비포복 하체의 투영 가림 범위를 유지해 돌출을 막았다. 승인 서기·앉기 픽셀은 그대로다.
- 실제 장전 시작 시각과 남은 시간으로 지지손이 탄창 접점을 왕복한다. 장전 취소·완료 시 잔여 표시 변위를 최대 0.12초에 복귀한다. 탄약 적용·취소 판정은 엔진만 소유한다.
- 같은 경기 시각은 같은 프레임을 유지한다. 시간 역행, 0.5초 초과 관측 공백, 80단위 초과 위치 불연속, 층 변경, 포복/다운/사망 진입은 이전 전환을 폐기한다. 동작 감소에서는 보행·손 왕복을 생략한다.
- 성능 데이터, 히트박스, 시뮬레이션 발사 원점은 변경하지 않았다. 표시 총구의 기존 반동 계약도 유지한다.
