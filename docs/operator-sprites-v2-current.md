## 단계와 실제 변경

1단계 연결 완료. `operatorStateVisual`은 기존 걷기·저자세 24시트를 선택하며 정지/조준/사격은 두 번째 통과 프레임을 고정한다. `BroadcastCanvas`는 `drawOperatorSheet`를 먼저 호출한다. 시트가 없거나 로딩 중인 경우만 `paintMinimalOperator`를 사용한다. 장전·구조·틀 넘기·달리기·사망 및 미제작 다운 자세는 폴백이다. COLLIER의 기존 다운/다운 이동 시트는 사용한다. 횡이동·후진에는 앞걸음 시트를 강제로 재생하지 않는다.

`drawOperatorSheet`는 원래 region/pivot/scale을 사용하고 총기를 따로 덧그리지 않는다. `sheetMuzzlePosition`은 같은 프레임 앵커로 화염과 예광탄 표시 시작점만 계산한다. 사건 객체와 시뮬레이션 총구는 변경하지 않았다. 폴백은 기존 총기 PNG를 몸보다 먼저 그려 개머리판을 어깨 뒤로 가린다. 코드 팔·새 무기 도형은 추가하지 않았다.

2단계 게이트 구현 및 기존 24시트 측정 완료. 다만 알려진 COLLIER 총열 형태 불량을 앵커 거리로 검출하는 문제는 미해결이다. 신규 이미지는 생성하지 않았다. 3단계 다운 11명, 4단계 전용 idle/Tier 2, 방패는 미착수다. 사용자 명세 9절의 ‘연결 화면을 먼저 보고 판단’ 순서에 따라 사용자·Claude 화면 피드백 이후 진행한다. 브라우저 검증은 수행하지 않았다.

## 측정 결과

원본 WebP/메타데이터는 수정하지 않았다. 24시트/96프레임의 실측 배열은 `validation/operator-sprite-audit.json`에 있다. 검사는 불량이 있으면 종료 코드 1을 반환한다. 아래 실패를 통과 처리하지 않았다.

면적 기준은 네 bbox 면적 평균 대비 최대 편차다. 몸체/총기 분할 마스크가 없으므로 4·5의 bbox는 인물+총기 전체 실루엣의 대리값이다. 프레임1/3 하단 RGB 밝기에 alpha를 곱한 픽셀 분포 상관을 사용한다. 경고의 색 범위와 최소 연결 면적은 검사 코드에 공개했다.

COLLIER 저자세 확대 확인: 총구 앵커는 걷기와 비슷하지만 전방 총열이 굵은 검은 원통처럼 보여 파지가 뭉개진다. MAGPIE 걷기는 전완·장갑·카빈 파지가 읽힌다. 이 육안 차이를 길이 임계값만 임의로 낮춰 실패시키지 않았다. 알려진 불량을 검출하는 게이트 보완은 남아 있으므로 새 생성물의 품질 검수가 완성됐다고 주장하지 않는다. 기존 승인 시트는 1단계 화면 검토 대상으로 연결하며 새 탈락 후보를 런타임에 반입하지 않았다.

## 검증

- 상태 계약: 24클립의 4프레임/정지 통과 프레임/특수 행동 폴백/시간·입력 불변 통과. 수정 전 정지 프레임 계약이 실패한 뒤 연결 수정으로 통과했다.
- 실제 Canvas: 24시트×4프레임×8방향 768합성, 한 번만 그리기, 화면 총구와 프레임 변환 일치, 로딩 폴백 통과. Skia float32 오차 0.000016단위를 확인하고 허용 오차를 0.0001단위로 설정했다.
- 실제 중계 Canvas 16장면과 터치 좌표 통과. 걷기/저자세 시트가 실제 경로에서 그려지고 시트 경로가 분리 총기를 호출하지 않는 것을 검사했다.
- 엔진과 무기 총구 계산 소스는 기준 커밋과 바이트 일치. SHA 기록은 `validation/operator-sheet-contract.json`. Worker 빌드 결과도 기존 `tactical.worker-DudZ_aEc.js`다. 전체 경기 회귀/밸런스 배치는 이번 표현 변경에 재실행하지 않았다.
- 타입 검사와 프로덕션 빌드 통과. 픽셀 게이트는 위 3건 실패로 별도 유지한다.

정적 중계 합성에서 원화와 미제작 동작 폴백이 섞여 보이는 한계를 확인했다. 실제 브라우저 관전, 모바일 체감 품질, 전체 인물의 해부학·동작 연속성 승인은 사용자와 Claude 확인이 필요하다. 원문처럼 우선 정지·걷기·저자세 장면을 캡처해 주면 다음 제작 기준으로 사용한다.
