# 실제 스프라이트 검수 기록

## 최신 갱신 — 행동별 시트 방식

사용자 피드백에 따라 수십 가지 혼합 포즈/시트와 한 프레임당 생성 방식을 기본 제작에서 제외합니다. 한 행동의 연속 4~6프레임을 한 시트로 제작합니다. 아래 이전 검수 이력은 보존합니다.

- COLLIER 다운 정지: `collier-downed-v3.webp`, 1024×459, 164,200바이트. 고해상도 단일 원본을 재사용했습니다.
- COLLIER 다운 이동: `collier-downed-crawl-v1.webp`, 1024×438, 163,088바이트, 4프레임. 각 원본 인물 장축 693~748px이며 이전 36칸 시트의 약 209px 셀을 확대해 만든 것이 아닙니다.
- 배경 제거·색 번짐 제거·정렬·압축은 승인된 오프라인 후처리로 일괄 수행합니다. 실제 투명도, 인접 셀 손·발 혼입, 프레임별 원본 해상도와 일정한 기준점을 검사합니다.
- Canvas와 SVG가 실제 다운 이동 시각에 같은 시트를 사용합니다. 정지 지혈에는 정지 원화가 나오며, 사격 총구·엔진 결과·개인 시야 규칙은 변경하지 않습니다.
- 파지·슬링에 의해 주무기가 몸에 지지되고 왼팔·다리의 이동 단계가 서로 다른 것을 확인했습니다. 특정 MP5SD 형식·제식 장비의 전 부품 고증과 실제 브라우저 재생 품질은 미확인입니다. 4프레임 저속 부상 이동이며 걷기·달리기를 대체하지 않습니다.
- 제작된 연속 행동 시트는 **COLLIER 다운 이동 1종**입니다. 전원 풀 팩과 신규 오퍼레이터는 여전히 미완료입니다. 목록은 `docs/operator-action-production.md`를 봅니다.
- 생성 원문·무편집 원본·재실행 좌표는 `art-source/operators/collier/`, 처리기는 `scripts/prepare-operator-sprite.py`에 보존합니다.
- 이번 실행: 타입 검사·프로덕션 빌드, 원본 해상도/투명도/시트/원점/무확대 검사, 12명 자산 계약과 4프레임 선택 검사, React/SVG 5개 검사, 실제 seed 41 스냅샷의 Canvas 6장 렌더가 통과했습니다. SVG 추가 사례는 합성 UI fixture이며 경기 발생 증거가 아닙니다. 엔진 규칙은 수정하지 않았습니다.
- `validation/collier-crawl-asset-review.gif`는 네 원화의 루프 확인용이며 게임 녹화가 아닙니다. `validation/action-sheet-canvas-crawl.png`는 실제 시뮬레이션 스냅샷을 로컬 Canvas에 그린 결과입니다. 해당 실행의 6개 렌더 측정 기록은 `validation/action-sheet-canvas-review.json`에 있으며 선택한 한 PNG를 보존했습니다. 브라우저 보안 차단으로 실제 개발 화면 플레이와 iPhone 실기 성능은 미확인입니다.

## 이전 검수 이력

기준: main 6504c83에 있던 전투 인물 12명(개별 3장 + 9인 아틀라스), 초상 3장 전부 직접 열어 확인했습니다. 자동 검사는 투명도·파일·좌표 계약을 검사하며, 육안 검수나 제조사 고증을 대체하지 않습니다. 기존 원본은 삭제하지 않습니다.

## 이번에 실제 연결한 것

- `collier-portrait-v2.png`: 기존 잘못된 소총형 초상 교체. 원본은 보존. MP5SD형 총몸·가느다란 탄창·통합 소음기·파지 형태 개선. 특정 MP5SD 세부 형식의 인증된 재현은 아님.
- `collier-poses-v2.png`: 네 자세 시안 중 **오른쪽 아래 다운 자세만** 입고. 다른 셀은 미사용 시안이며 걷기·달리기 프레임으로 쓰지 않음.
- 다운 프레임 범위 `[910,565,610,405]`, 몸 중심 `[290,210]`, 배율 `0.1`, 원화 방향 보정 `0.45 rad`. 쓰러진 몸을 서 있는 상체로 표현하던 COLLIER의 실제 `downed` 상태에만 사용.
- 사격 가능한 기존 원화·물리 총구·엔진·난수·체력 규칙은 변경하지 않음. 다운 원화의 `muzzle`은 자료형 필수 좌표일 뿐 발사 계산에 사용하지 않음.
- 알려진 아군 다운 자산은 미리 읽음. 새 PNG 두 장의 합계는 약 3.5 MB로, 전원 확장 전 별도 해상도·압축 최적화가 필요함. 이번에는 생성 원본의 픽셀을 변경하지 않음.
- 다른 11명에게 COLLIER의 몸을 복제하지 않음. 다운 이후 사망 전환·구조 복귀의 연속 애니메이션은 미완료.

## 탈락한 후보

COLLIER 24프레임 시트와 배경 추출 재시도 모두 1024×1536 **RGB / 알파 255 고정**. 회색 체크무늬와 흰 흔적이 이미지 픽셀에 포함되어 실전 사용 불가. public 또는 앱에 연결하지 않았습니다. 달리기 두 프레임의 보행 위상·파지의 연속성도 추가 검수가 필요합니다.

## 전체 팩의 완료 기준 (현재 완료 0명)

정지 조준 / 사격 복귀 / 걷기 / 달리기 / 앉아 이동 / 엎드림 / 포복 / 장전 / 투척 / 가젯 설치 / 브리칭 / 문틀·창문 넘기 / 목표 설치·해제 / 구조 / 다운 대기·이동 / 사망을 실제 상태·사건과 연결해야 합니다. 이동 루프에는 지지발과 골반 이동이 일치하는 연속 프레임이 필요합니다. 단일 포즈를 흔들거나 두 비슷한 포즈를 반복하는 것은 완료가 아닙니다.

신규 오퍼레이터는 공격·수비 각 1명을 계획했으나 **아직 추가하지 않았습니다**. 현재 후보 제작이 투명도·동작 품질을 통과하지 못한 상태에서 이름과 능력치만 등록하면 빈 자산·가짜 완성 범위를 늘리므로 보류했습니다. 기존 오퍼레이터 설정·저장 데이터는 변경하지 않았습니다.

## 재실행

`node tests/operator-sprite-audit.cjs`: 전원 자산 계약과 다운 프레임 범위, 실제 알파 검사. 오프라인 검사에만 Python/Pillow 사용. 이미지 수정 없음, 게임 런타임 의존성 추가 없음.

`node tests/operator-sprite-audit.cjs /absolute/path/candidate.png`: 새 자산의 실제 투명 채널 사전 검사. 불투명 체크무늬 시트는 실패 종료.

자동 검사 / 로컬 Canvas 렌더 / 실제 브라우저 플레이 / Replit 반영은 각각 별도로 보고합니다.

이번 검사: 타입·프로덕션 빌드, 기존 실시간 21개, 부상 12개, 관전 연속성 10개, React 서버 렌더 3개 통과. 자산 계약 12명+다운 셀 통과. 실제 경기에서 COLLIER가 다운된 스냅샷을 사용한 Canvas 렌더까지 확인. 로컬 Skia가 원본 PNG 디코딩을 거부하여 PNG CRC 검사 후 **테스트에서만** Pillow로 재인코딩했음. 원본이 실제 브라우저에서 로드되는지는 별도 확인 필요. 개발 URL을 직접 열었을 때는 실행 안내 화면이 나와 플레이하지 못함. 아이폰 성능 검증 아님.
