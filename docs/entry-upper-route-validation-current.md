# 출발 시차·상층 경로 검사 복구 — 2026-09-13

기준 커밋 `bfe5ea8327973b6eda907ad1848e5c4e27e68512`(PR #10). 이전에 남긴 두 실패를 재현했으며, **게임 엔진 결함이 아니라 오래된 검사 입력·측정 구간의 결함**으로 확인했다. 게임 코드·지도·피해·시차·설치 규칙은 변경하지 않았다.

## 실제 재현과 원인

| 검사 | 이전 실패의 원인 | 바로잡은 조건 |
|---|---|---|
| `node tests/entry-formation.cjs` | 준비 단계 0.3~0.4초의 대기선 이동을 출발로 계산. 실제 entering 시작은 15초인데 검사가 그때 끝남 | entering 직전 위치를 기준으로 진입 이후 15초를 측정. 최초 스폰의 실내 금지·70단위 간격, 이동 판정15단위, 출발 분산2.5초 기준 유지 |
| `node tests/vertical-routes.cjs` | 방어 임무 위치만 격리하고 공통 수비 스폰은 기본값 유지. 서쪽 경로는 상행·해치·하강 후 59.2초 수비 전멸로 종료 | 공통 수비 스폰과 집결 반경을 격리실 안에 지정. 수비의 실제 위치·생존을 모든 스냅샷에서 검사하고 사격 사건 0건을 추가로 요구 |

출발 검사에는 준비 단계 30초 이내 종료, 실제 entering 도달, 각 선수의 0.9초×순번 이전 이동 금지도 추가했다. 준비 시간과 진입 검사 시간을 분리한 것이며 진입 후 허용 시간을 늘리지 않았다. 상층 검사는 적 제거로 끝내지 않고, 실제 상행·해치 개방·하강·설치를 모두 요구한다.

## 결과

- 영향 범위 회귀 묶음 **15/15 통과**. 이전 13통과·2실패에서 두 검사 복구까지 포함해 한 번의 전체 실행으로 확인했다.
- 다섯 진입로 모두 entering 시작 15초. 15단위 이상 이동한 첫 선수와 마지막 선수의 시간 차이 2.9~3.7초로 기존 2.5초 조건 통과.
- 서계단→송출 해치: 69.6초 설치. 동계단→배전 해치: 65.6초 설치. 양쪽 모두 무교전·실제 층 이동·해치 개방·설치 확인.
- `tests/entry-route-negative-controls.cjs`: 실제 소스/입력을 메모리에서만 변형해 출발 시차 제거, 격리 스폰 누락, 설치 행동 차단을 각각 주입했다. 세 경우 모두 의도한 assertion에서 실패해 감지했다. 작업 파일을 덮어쓰거나 실패를 pass로 바꾸지 않는다.
- 앱 타입 검사·공용 라이브러리 타입 검사·프로덕션 빌드 통과. 빌드 자산 해시도 PR #10과 동일하며 게임 엔진 SHA-256은 `9d27eb7b2ac18b43706b8d9178fa138d67141723d4ec876d1f360dc249066855`로 유지된다.

원시 결과: `validation/entry-formation.json`, `validation/vertical-routes.json`, `validation/entry-route-negative-controls.json`. 전체 회귀 묶음은 `tests/ai-traffic-validation.cjs`와 `validation/ai-traffic-regressions.json`을 사용한다. 이전 실패의 실행 증거인 `validation/ai-traffic-baseline-check.json`은 과거 기록으로 보존했다.

## 정정과 범위

이전 보고의 ‘기존 회귀 2개 실패’는 실행 사실로 맞지만, 게임의 출발·상층 설치 자체가 깨졌다는 뜻은 아니었다. 이번 검사 복구로 구분했다. 회귀 복구는 새 게임플레이 개선이나 공격 승률 상승이 아니다.

브라우저·청음 검증과 QA40 전체 배치는 실행하지 않았다. 잔여 판단 왕복, 장기 통행 대기, 공수 밸런스·소생률과 화면 QA는 여전히 미완료다. 다음은 실제 관측 단절과 목적지 반전을 구분하는 판단 왕복 추적, 예약 소유자·몸 충돌 대기 그래프 재현이다.
