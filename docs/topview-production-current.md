# 현재 작업 프롬프트 — 탑뷰·고유 문양·QA 후속

목표: 가파른 탑뷰 지도·인물·총기를 같은 투영으로 통일. 승인 측면 총기 수준의 개별 탑뷰 PNG와 고유 오퍼레이터 문양 PNG를 제작·연결한다. QA 권장 순서의 표시 계층과 감독 지시 연결을 진행한다.
완료 조건: 실제 투명 원화, 무기별 식별/총구/파지 정렬, 연속 회전, 모바일 가독성, QA 항목별 현재 상태 기록과 테스트. 생성 시안과 실제 연결을 구분한다.
제약: 기존 스택·능력치·저장 선수·결과 판정 보존. 거부된 코드 총기 재사용 금지. 기존 승인 측면 원화 보존. 각 작업/총종별 프롬프트 재작성. 로컬/서버 검증과 실기기 검증 구분.
현재 근거: 첨부 QA 원문 수령. 구버전의 standing body/weaponUp는 현행과 다르며 개별 항목을 재검사한다. 본문에는 오퍼레이터 세대 데이터가 없으므로 새 색상 그룹은 아트 메타데이터로 두고 능력치·공수 색과 분리한다.
다음 행동: 엄격한 수직 탑뷰 L119A2 개별 PNG로 시점·알파를 검수한 뒤 같은 제작 규격을 총종별로 조정한다.

공통 총기 프롬프트: 실제 군용 총기 구조를 가진 독립 래스터 에셋. 수직 90도 정사영 탑뷰, 총을 정상 파지했을 때 위에서 내려다본 상부만 보임. 총구 오른쪽/개머리판 왼쪽 수평. 리시버 상면·피카티니 레일·광학장비 상면·개머리판 어깨패드·전방부 구조를 정확히 구분. 측면 탄창/권총손잡이를 옆으로 펼치지 않음. 금속 흑색·올리브·코요테색, 정돈된 2~3단 명암, 균일한 굵은 어두운 외곽, 고급 게임 스프라이트 밀도. 전체 총기와 여백, 실제 투명 알파 PNG, 손/문자/그림자/배경 없음.


## 구현·검증 결과

- 원본 총기 12종: 2172×724 RGBA, 실제 투명 알파. 리시버 측면이 섞인 HK417/AS Val 초안, 잘못된 MP5 조작부 초안, 총구 화염이 포함된 P90 초안은 적용하지 않았습니다.

- 4열×3행 생성 엠블럼 시트, 12개 서로 다른 상징. UI는 원본 배지 범위만 표시하고 도형으로 문양을 대체하지 않습니다. 미확인 상대는 문양·신원을 숨깁니다.
- QA P1-06/07/10/11/13 표시 수정, P0-03 기존 감독 명령의 워커·대체 실행 연결, P2-21 종료 표기, P2-22 사망 사수 자동 추적 수정.
- 명령 없이 실행한 1·2·4배속의 결과와 사건 순서는 기존 엔진과 동일합니다. 지시 4종은 실제 세션 로그로 확인했습니다.
