# 준비 단계의 투척 누락과 회귀 입력 복구

기준: 추가 QA 실행 후 로컬 30cb0aa / 원격 2473331. 양 팀 15초 준비를 유지하며 엔진의 공격 투척 분기에 동일한 준비 잠금을 적용했다. 임의로 준비 시간을 없애거나 공격 성공 사건을 주입하지 않았다.

## 실제 결함

`TacticalRealtimeSimulation.runTicks`는 `shouldFire`와 장약에 준비 잠금을 걸었지만 연막/수류탄의 공통 공격 분기에서는 빠뜨렸다. 가까운 적을 보는 검사 입력에서 준비 시작 0.9초에 수류탄이 나갔다.

동일한 갱신 입력을 수정 전 190797e의 별도 작업본과 수정 후 엔진에서 실행했다. 최초 투척은 0.9초 → 15초, 실제 회피 상태는 0틱 → 10틱이었다. `validation/preparation-throw-before-after.json`에 사건 시각과 입력 출처를 보존했다. 이 한 표본으로 모든 가젯과 모든 경기의 회피 품질을 보장하지 않는다.

검사 대상 사건이 없을 때 통과시키는 분기나 사건 수 임계값 완화는 넣지 않았다. 22단위 틈은 인지 격리를 위한 합성 검사 지형이며 실제 남산 맵의 변경은 아니다.

## 검증

**최종 회귀 14개 전부 통과.** 최종 실행은 `validation/preparation-combat-fix-suites.json`의 14개 스위트와, 검사 지형 합법성 보강 후 재실행한 `validation/preparation-fixture-final.json`을 따른다. 타입 검사·프로덕션 빌드도 실행했다. 기존 실패 원본은 `qa-verify-baseline.json` 및 `qa-verify-suites.json`에 유지한다.

그룹별40경기(반복 포함160회) 재측정은 `qa-verify.json`과 `qa-verify-output.txt`, 수정 전 비교는 `before-preparation-fix-qa-verify.json`에 기록한다. 이 변경은 명중률·소생률·순환대기 등의 기존 실패를 해결했다고 주장하지 않는다. 개별 스프라이트/녹음 사운드/캐릭터 검수도 별도 미완료다.

## 이펙트 제작 착수

HK416 탑뷰 원화를 참조해 독립 총구 화염 1종을 내장 이미지 도구로 생성하고 배경 제거 수정을 한 번 요청했다. 두 결과 모두 RGB 1774×887, 투명 픽셀 0%로 규격에 실패했다. 체크무늬를 알파로 오인하지 않고 둘 다 게임 적용에서 제외했다. 원화 시도는 완료 자산 개수에 포함하지 않는다. 프롬프트는 `art-source/effect-prompts-v1.json`, SHA·크기·탈락 사유는 `validation/muzzle-generation-rejected.json`에 보존했다.

재측정 완료: 자동38개 **24통과·11실패·3보류**, 모든 표시 수치가 수정 전과 동일했다. 준비 중 교전이 발생하는 별도 고정 교전 입력에서는 결함이 재현·해소되지만, 이 160회 모집단에서는 기존 밸런스 실패가 개선되지 않았다.
