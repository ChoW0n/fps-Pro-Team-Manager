# DRAFT ORDER: 실제 관전 경로 개편

## 후속 작업 기준 — 사용자 최신 요청

기존 패치와 점수판 보정은 GitHub main 0843bcf1f71f0363427c252a51bcb3ceefebbf7d에 반영됐습니다. 실제 경기 종료·선수 선택·카메라·명령 검증 기록은 validation/browser-playthrough-20260910.md에 있습니다. 아래 과거 미반영 기록은 당시 상태이며 현재 완료 여부와 구분합니다.

사용자의 `초원_AI_게임개발_협업_마스터프롬프트.md`를 전체 읽고 적용합니다. 최신 추가 요청은 큰 시설과 작은 인물 비율, 폭탄 방어·해체 기반 목표전, 이동 떨림·끼임 해소, AI와 디자인 개선입니다.

작업 묶음: (1) 맵·비율·이동 품질 (2) 폭탄전 규칙과 팀 임무 (3) 관전 정보·디자인·실제 플레이 검증. 승자 선결정, 시각으로 이동 오류 숨기기, 저능한 기본 동작을 낮은 능력치로 정당화하는 것은 금지합니다.

폭탄전 목표 규칙: 수비는 A/B 폭탄을 지키고 공격은 한 사이트에 해체 장치를 설치해 엄호합니다. 수비는 작동 중인 장치를 무력화해야 합니다. 설치 전 공격 전멸·시간 초과, 설치 후 공격 전멸, 장치 회수, 설치/무력화 중단, 해체 완료 등 각 종료 조건을 분리해 검증합니다. 수치와 세부 판정은 구현 시 게임용 규칙으로 명시합니다.

기존 엔진의 고정 선수·시드 8개 180초 감사에서 연속 이동 방향의 120도 초과 반전이 경기당 1,252~5,146회였습니다. 모든 입력의 첫 발사 시점은 0초였습니다. 이는 품질 관찰 지표이며 단일 원인을 확정한 결과는 아닙니다. tests/movement-audit.cjs와 validation/movement-baseline-20260910.json에 재실행 방법·원자료가 있습니다. 수정 전후에는 같은 측정을 사용하고 정당한 수비 대기를 버그로 세지 않습니다.

추가 비교 자료: https://www.youtube.com/watch?v=7mkOkyyBA0w — 방구석 게임평론가 쥐냥의 「이스포츠 매니저 2026」 리뷰. 영상 제목·설명·3:40 AI 비판 챕터와 공개 댓글을 확인했습니다. 전체 자막은 제공되지 않았으므로 전체 시청·세부 비판 전수 분석·현재 제품 상태나 상업적 실패 확인으로 과장하지 않습니다. 우리 코드에서 재현한 문제를 직접 고치고, 임무 유지·통로 통과·정보 제한·설치/무력화 협동을 완료 기준으로 삼습니다.

## 변경

- 기존 App → TacticalRoundLive 경로에 인물 중계 연결. 별도 데모 진입점 없음.
- MAGPIE, COLLIER, 해동: 첨부 WebP 초상·탑다운 원화 사용. 다른 인물은 임시 벡터 몸체와 무기 유형 표현. 임시 상태를 카드에 표시.
- 실제 facing으로 회전. public/operators/manifest.json의 pivot·muzzle을 동일한 배율로 세계 좌표에 변환. 엔진의 발사 원점과 화면이 이 함수를 함께 사용.
- 실내 벽 단면·문틀·책장·랙·책상 표현은 기존 충돌 지형에서 생성. 장식용 장애물을 별도로 추가하지 않음.
- 전체 전황, 선수 확대, 자동 중계, 작은 전략 지도, 참가자 ID 기반 선수 선택·초상·체력·탄약.
- 명령은 다음 예정 틱으로 큐잉. 클릭 횟수가 경기 틱을 즉시 소비하지 않음. 일시정지와 배속은 세션 소비만 조절.
- 같은 콜사인의 능력치 조회·교전 결과·선택 상태를 참가자 ID로 분리.
- 아군 소리 오인 보고 제거. 소리 원 발생 시각 보존. 실제 팀 보고를 빠짐없이 기록.
- 탄착을 발사 당시 위치에 고정. 이동한 적을 자동 추적하는 피해 제거. 탄착 때 시야·몸 반경 재검사. 사망 체력 0, 속도 0, 장전 종료.
- 떨어진 공선 선분의 잘못된 교차 판정 수정. 초기 수비 위치와 책장 안의 경유점 수정. 엄폐물 모서리 경유점 추가, 모서리 조기 생략 방지, 아군 겹침 예외 제거.
- 고정 지형 노드 연결 캐시로 반복 경로 탐색의 동일 지형 판정 감소. 경로 끝에서 거점 접근까지 진행.
- 수비 거점 담당 두 자리는 간접 정보만으로 수색하지 않음. 직접 교전·생존 재배치는 유지.

## 재실행

프로젝트의 설치된 TypeScript를 사용합니다. 추가 테스트 라이브러리는 없습니다.

```sh
node tests/realtime-regression.cjs
node node_modules/typescript/bin/tsc -p artifacts/draft-order-player-generator/tsconfig.json --noEmit
PORT=5173 BASE_PATH=/draft-order-player-generator/ node artifacts/draft-order-player-generator/node_modules/vite/bin/vite.js build --config artifacts/draft-order-player-generator/vite.config.ts
```

회귀 검사 결과는 validation/realtime-results.json에 저장됩니다. 고정 입력 실행 비교와 작은 탄창의 장전 유도 입력을 구분합니다. 실제 경기 15회라는 뜻이 아닙니다. TypeScript 타입 검사는 앱 범위이며 워크스페이스 전체 서버 검사를 의미하지 않습니다.

## 직접 관찰한 화면과 미확인

- 원래 Replit 개발 화면에서 준비 → 실제 수동 밴픽 → 경기 → 감독 명령 → 시간 종료까지 조작했습니다.
- 기존 화면에서 도형만 표시, 공격수 입구 정체, 음수 사망 체력을 확인했습니다. baseline screenshot은 validation/browser-before.jpg입니다.
- 기존 화면에는 선수 선택 컨트롤이 없었습니다. 이번 소스에서 추가했지만 수정 버전의 브라우저 플레이는 아직 확인하지 못했습니다.
- 이 환경의 브라우저는 로컬 URL 접속을 보안 정책으로 차단합니다. 별도 브라우저나 우회 주소로 회피하지 않았습니다.
- GitHub 연결의 브랜치 생성은 403 Resource not accessible by integration. 로컬 git push는 인증 없음. Replit은 이 ChatGPT 채팅의 첨부에 직접 접근할 수 없다고 응답했습니다.
- Replit 개발 앱으로 이번 변경을 전송하지 못했습니다. 공개 배포도 갱신하지 않았습니다. 수정 화면의 전체·교전 스크린샷은 없습니다.
- Replit 조회 요청에 Free 제한을 명시했지만 실제 계정 과금 모드는 연결에서 검증할 수 없다는 응답입니다. Power/Max/업그레이드/유료 API를 요청하지 않았습니다.

## 남은 기획·품질 항목

선발조 0~3명, 25/40/55/70초, 실제 복귀·합류·재진입 흐름은 아직 없습니다. 현재 고정 12초 수색입니다.
MOBA 밴픽·선수 저장 계약은 보존된 상태이며 정식 FPS 오퍼레이터 픽 전환은 별도 작업입니다.
다중 라운드·공수 교대·설치/해제는 미구현입니다. 전멸 또는 제한 시간 종료 시 거점 주변 인원 비교가 현 종료 규칙입니다.
기존 요약 수치 모델의 계수는 변경하지 않았습니다. 급함 공식의 불일치는 유지된 검증 안건입니다.
정지 원화를 이동/장전/사망 연속 프레임으로 간주하지 않습니다. 총기 외형과 무기 임시 수치는 제조사 고증 전입니다.
충돌 회귀 검사는 특정 입력에서의 확인이며 모든 지도·시드의 AI 품질 보장이 아닙니다. 사용자 PC 성능은 시험하지 않았습니다.
