# 확장 시설·이동 안정화·폭탄전 연결

기준 원격 커밋은 `8fba9f543656a9cc6caa7e983efe74ae441623db`입니다. Replit이 완료한 맵·렌더러·원화 비율을 직접 읽고 로컬 이력과 일반 병합했습니다. 원격 README와 두 부모 이력은 보존했습니다. 이후 Replit Agent에 개발 요청을 추가하지 않았습니다.

## 실제 변경

- 3600×2400 시설에서 중복 벽이 문을 덮던 오류와 남서 해치 외벽을 수정했습니다. 초기 배치, 문 중심, 외부→내부 진입, A/B 설치·방어 지점은 몸 반경 검사를 통과합니다. 모든 초기 공격 경로에서 두 설치 지점까지 경로가 존재합니다.
- 몸 반경은 12, 벽 반두께는 9입니다. 원화 비율 0.11과 임시 인물 비율 0.75를 총구 함수와 함께 사용합니다. 이는 게임용 월드 단위입니다.
- 경로를 픽셀마다 버리는 동작, 시간에 따라 왕복하는 수색 목표, 동료 방향에 따라 급변하는 지원 목표를 제거했습니다. 회피 경유점은 먼저 확정한 뒤 실제 보행으로 통과합니다. 좁은 문은 예약과 대기로 한 방향씩 통과합니다.
- 가까운 실제 엄폐로 후퇴하고 장전 목적지를 유지합니다. 개인 시야는 거리 1200, 전방 144도, 근접 60, 벽 판정을 함께 사용합니다. 보고는 관측 위치이며 실제 적 좌표가 아닙니다. 가까운 관련 보고와 기존 보고에 우선순위를 주어 팀 전체가 새 총성마다 왕복하지 않게 했습니다.
- `BombObjective`를 기존 `runTicks()`에 연결했습니다. 공격은 한 사이트에 해체 장치를 설치·엄호하고 수비는 폭탄을 방어하거나 설치된 장치를 무력화합니다. 운반자 이탈 시 실제 위치에 장치가 유실되고 동료 한 명이 도달 가능한 경로로 회수합니다. 가동 후에는 수비 한 명에게 무력화, 나머지에게 엄호 임무를 부여합니다.
- 장치 설치 7초, 무력화 7초, 가동 45초는 프로젝트의 게임용 규칙입니다. 최신 외부 게임 대회 규정으로 주장하지 않습니다. 제한 시간 직전에 시작한 설치는 이어갈 수 있고 중단하면 수비 승리입니다. 설치 후 공격 전멸만으로 끝나지 않습니다. 장치 가동 완료와 무력화 완료가 같은 틱이면 이미 도달한 가동 완료가 우선합니다.
- 관전에는 실제 장치 위치, 운반자, 설치·무력화 진행, 목표 종료 사유가 표시됩니다. 전체 지도·자동 중계·선수 확대는 같은 상태를 사용합니다. 자동 카메라는 대상을 최소 4초 유지하고 확대 배율은 4.5/5.8입니다.
