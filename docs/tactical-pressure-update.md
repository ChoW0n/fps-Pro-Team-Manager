# 전술 인지·차폐·표현 전환 기록 — 2026-09-11

## 적용

- FoV의 기존 후방 차단·회전 속도 제한을 유지하고, 거리/부분 노출/관측 기량/집중 조준경에 따른 연속 인지 시간을 추가했습니다. 기하학적으로 보이는 것과 식별 완료를 구분합니다.
- 공개 CombatSkills는 거리 선호·위험 인지·초탄·반동·반응·가젯 타이밍입니다. 이전 선수 저장에는 공개 스탯으로 기본값을 계산하며 선택적 개별 값도 받을 수 있습니다. 숨은 composure는 공개하지 않습니다. 독립 육성 UI는 아직 없습니다.
- 사격 효율 추정으로 불리한 긴 사선을 피하고 엄폐·연막을 선택합니다. 실제 명중은 종전의 시드 탄도·탄착·피격 판정입니다. 15m 명중률 절벽, 무조건 SMG 패배, 스폰 무적, 보이지 않는 벽은 넣지 않았습니다.
- 실제 비행 완료 탄환의 가까운 통과/탄착으로 압박을 누적하고 시간에 따라 회복합니다. 높은 압박은 사격 제어와 엄폐 선택에 영향을 줍니다. 평정심 수치를 게이지로 공개하지 않습니다.
- BRANDT/HALLORAN에만 2.5배 집중 관측과 느린 기동을 설정했습니다. 현행 레식의 모든 조준경 규칙이나 실측 총기 성능을 복제했다고 주장하지 않습니다.
- 다섯 스폰의 실제 트럭 엄폐, 중앙 아트리움의 두 실제 차폐물, 두 외벽 파쇄 패널을 추가했습니다. AI는 거점 근처의 도달 가능한 엄폐·코너를 선호합니다. 모든 직선 사선이 25m 이하라는 검증은 하지 않았습니다.
- 공격 3+2 등 두 경로 편성, 각 경로 수색·복귀·합류·재진입을 연결했습니다. 0명 수색은 즉시 진입합니다.
- 수비 5번 선수의 공용 준비로 카메라/외벽 보강/차폐 방패를 선택합니다. 보강과 방패는 실제 이동 후 2초 설치입니다. 출입구·동료 충돌을 검사하고 관측 위협은 설치를 중단시킵니다.
- 보강은 일반 파쇄를 막습니다. MEDVED는 보강에 4초 관통 장약을 설치해 실제 통로를 냅니다. 벽 절단은 엔진과 렌더러의 같은 기록을 사용합니다. 전기/EMP/투척물 요격은 아직 없습니다.
- 아군은 카메라 방향과 무관하게 표시합니다. 적은 팀의 현재 식별과 기하 시야를 요구하고, 접촉이 끊기면 고정된 마지막 목격 표식만 잠깐 남깁니다. 숨은 위치를 따라 그리지 않습니다.
- 다른 방에서 온 보고만으로 구조를 무조건 포기하던 조건을 좁혀, 구조자가 실제로 노출된 위협을 확인합니다. 실제 사격으로 다운된 동료를 엄폐 뒤에서 구조하는 별도 입력을 저장했습니다.
- 미니멀 파츠를 실제 주 중계와 선수 카드에 연결했습니다. 상세 아트 범위와 중단 목록은 operator-action-production.md를 참조합니다.

## 재실행과 근거

루트에서 node tests/tactical-pressure.cjs, node tests/combat-overhaul.cjs, node tests/injury-regression.cjs, node tests/minimal-military.cjs, node tests/ui-render-contract.cjs를 실행합니다.

주 Canvas 검사는 DRAFT_REVIEW_DIR를 별도 폴더로 지정하고 node tests/render-broadcast-canvas.cjs를 실행합니다. 이는 실제 엔진의 저장 스냅샷을 로컬 Skia에 그리는 검사이며 직접 브라우저 플레이가 아닙니다. tests/render-defense-map.cjs는 실제 설치 스냅샷과 공통 지도 렌더러를 사용합니다.

타입 검사와 Vite 프로덕션 빌드는 별도 수행합니다. 런타임 의존성을 추가하지 않았습니다. Python/Pillow/배경 분리 도구는 아트 제작용이며 브라우저로 배포하지 않습니다.

## 미확인·남은 위험

- 브라우저 접근이 정책상 막혀 직접 플레이를 재개하지 못했습니다. 로컬 Canvas 수치는 iPhone 15 성능 인증이 아닙니다. 일부 렌더 표본의 지연이 남아 있어 모바일 성능 개선을 확정하지 않습니다.
- 일반 8개 이동 진단 시드가 모두 수비 승리였습니다. 이전 저장 진단도 같은 결과였지만 밸런스 해결을 뜻하지 않습니다. 일반 경기 4개 시드에서 소생은 0회였고 별도 구조 입력에서만 확실히 발생시켰습니다.
- 파츠는 두 머리 계열/공통 몸체/6무기 실루엣입니다. 고유 군장 12세트, 모든 상세 동작, 제조사·부대 고증 완성이 아닙니다.
- 설치형 방패의 파괴/회수, 전기·EMP·요격, 이동 드론, 양 거점별 독립 3침투 경로 감사, 층간 교전은 후속입니다.
- 공개 배포 갱신은 이번 동기화 범위가 아닙니다. Replit 반영 여부는 보고받은 커밋과 서버 상태로 별도 확인합니다.
