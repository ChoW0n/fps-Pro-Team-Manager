## 1. 이번 수정의 범위

1. **P90 발사 화염 버전을 레퍼런스에서 제외합니다.** P90 비발사형은 유지합니다.
2. 기존 이미지형 제작 가이드를 이 Markdown 문서로 대체합니다. 기존 가이드에 그려진 총기·설치 장비·로프는 캐릭터에 포함하라는 지시가 아닙니다.
3. 캐릭터 시트에서 무기별 들기 예시 영역을 제외합니다. 무기·가젯이 결합된 캐릭터를 완성 에셋으로 납품하지 않습니다.
4. 이 전달본에는 정리된 총기 레퍼런스 9장만 포함합니다. 기존 업로드 원본은 수정하거나 삭제하지 않았습니다.

이번 작업은 별도 원화 제작과 전달 기준 정리입니다. 기존 총기를 다시 그리거나, 엔진·게임 규칙을 바꾸거나, 저장소에 반영까지 완료했다는 뜻이 아닙니다.

## 2. 게임과 해결할 문제

플레이어가 개별 병사를 직접 조작하는 게임이 아니라, 전술 FPS 경기를 감독하는 2D 탑뷰 매니저 게임입니다. 여러 오퍼레이터의 위치·방향·행동·소속을 작은 화면에서도 구분할 수 있어야 합니다.

사용자가 보고한 문제는 총기에 맞춰 팔을 코드로 구성할 때 손이 손잡이에 맞지 않거나, 팔이 몸을 관통하거나, 관절이 부자연스럽게 꺾인다는 것입니다. 실제 코드 원인은 저장소 확인 후 판단합니다.

제작 목표는 **기존 총기 원화와 어울리는 캐릭터**, **읽기 쉬운 자세**, **무기와 독립적인 교체 구조**입니다. 팔을 무조건 길게 늘리거나 총을 몸통 한가운데에 붙여 문제를 감추지 않습니다.

## 3. 캐릭터에 포함할 것과 제외할 것

| 구분 | 기준 |
|---|---|
| 포함 | 인체, 빈손과 장갑, 전투복, 부츠, 헬멧·헤드셋·후드 등 헤드기어, 방탄복, 기본 파우치·백팩·하네스 등 착용 외형 |
| 제외 | 손에 든 총기·권총·칼·방패·투척물·고유 가젯·설치 장비·태블릿·가방형 장치 |
| 별도 에셋 | 로프, 발사 화염, 탄피, 연기, 투척 궤적, 발밑 그림자, 선택 표시, 부대·세대·팀 UI 표시 |
| 미포함 영역 | 소총·SMG·산탄총·저격총·권총을 실제로 든 비교 예시 패널 |

빈손은 자연스러운 자세 또는 향후 합성용 자세로 그립니다. **아무것도 들지 않는다는 뜻이지, 손이나 팔을 생략하라는 뜻이 아닙니다.** 투척·설치·레펠 자세도 빈손으로 제작하고, 물체가 들어갈 위치는 메타데이터로 전달합니다.

착용물 중 게임에서 교체되는 고유 장비는 캐릭터에 고정해서 그리지 않습니다. 복장 파츠와 행동용 가젯의 경계가 불명확하면 기존 오퍼레이터 설정을 먼저 확인합니다.

## 4. 아트 기준

### 4.1. 기존 총기와 맞출 시각적 특징

첨부된 비발사 총기들은 어두운 외곽선, 절제된 면 단위 명암, 저채도의 올리브·탄색·차콜 계열, 부분적인 마모와 재질 표현을 사용합니다. 이 특징을 캐릭터 제작의 기준으로 삼습니다.

- 선화 기반의 전술 밀리터리 일러스트로 제작합니다. 픽셀아트, 사진풍 3D 렌더, 둥근 도형만으로 된 임시 캐릭터를 섞지 않습니다.
- 총기와 나란히 놓았을 때 선 굵기·명암 단계·재질 밀도가 비슷하게 느껴져야 합니다. 비교는 원본 확대 화면보다 실제 게임 표시 크기를 우선합니다.
- 얼굴의 작은 묘사보다 헬멧, 어깨 폭, 조끼, 백팩, 팔과 손의 실루엣에 우선순위를 둡니다.
- 과한 광택, 검정으로 뭉개진 장비 경계, 잔무늬로 인한 시각적 노이즈를 피합니다.

### 4.2. 카메라와 방향

**기존 총기와 같은 수직 탑뷰를 우선합니다.** 정수리와 어깨 윗면 중심으로 보이게 하며, 얼굴·가슴 정면·다리가 크게 드러나는 사선 캐릭터를 그대로 섞지 않습니다.

방향 수는 실제 렌더러 확인 후 정합니다. 엄정한 수직 탑뷰라면 기준 방향 스프라이트를 평면 회전하는 방식을 우선 검토합니다. 앞선 예시의 `8방향` 표기를 모든 포즈의 필수 제작량으로 받아들이지 않습니다. 사선 투영을 실제로 채택한 경우에만 방향별 그림을 별도로 설계합니다.

기준 방향·회전 중심·광원은 캐릭터와 총기에 공통으로 적용합니다. 새 규약이 필요하면 첨부 총기와 같은 오른쪽 방향을 후보로 삼되, 기존 규약이 있으면 유지합니다. 비대칭 장비나 주손이 뒤집히는 단순 좌우 반전은 검수 없이 사용하지 않습니다.

### 4.3. 부대와 오퍼레이터의 구별

공용 포즈를 유지하면서 헤드기어 형상, 방탄복과 어깨 보호대, 파우치 배치, 백팩, 복장색, 제한적인 위장무늬와 개인 장비로 구별합니다. 얼굴이나 작은 패치만으로 개성을 해결하지 않습니다.

실제 부대의 장비 구성을 임의로 단정하지 말고 프로젝트에 이미 정리된 부대·오퍼레이터 설정을 우선합니다. 세대별 색상이나 팀 구분이 필요하면 기존 UI 규칙을 따르고, 원화에 선택 링이나 큰 식별 아이콘을 합쳐 넣지 않습니다.

## 5. 파츠와 포즈 제작 방식

기본 원칙은 **손으로 설계한 포즈 + 필요한 부분만 분리한 스프라이트 + 코드 합성**입니다. 모든 관절을 따로 나누거나 새로운 복잡한 리깅 시스템을 추가할 필요는 없습니다.

| 제작 단위 | 역할 |
|---|---|
| 하체 | 기본 자세와 이동 표현. 필요한 경우 상체와 분리합니다. |
| 몸통 | 전투복·조끼와 어깨 연결부의 기준입니다. |
| 팔·손 포즈 | 상체와 맞물리도록 그린 완성 포즈입니다. 임의로 팔 길이를 늘리는 재료가 아닙니다. |
| 머리·헤드기어 | 공용 포즈 위에서 외형을 바꾸는 단위입니다. |
| 외형 장비 | 교체가 필요한 파우치·백팩 등만 분리합니다. |
| 특수 자세 | 앉기·엎드리기·레펠 등은 해당 자세에 맞춰 다시 그립니다. 필요하면 몸 전체를 하나의 포즈로 제작합니다. |

팔을 교체할 계획이면 몸통 원본에는 해당 팔이 중복으로 들어 있지 않아야 합니다. 팔이 포함된 완성 캐릭터 위에 또 다른 팔을 덧붙이는 구조를 금지합니다. 완성 포즈 방식과 분리 파츠 방식은 하나의 상태 안에서 중복 사용하지 않습니다.

엎드리기나 레펠을 서 있는 그림의 축소·찌그러뜨리기·관절 회전만으로 대체하지 않습니다. 특수 자세를 몸 전체로 제작하더라도 **무기와 가젯은 반드시 분리**합니다.

## 6. 필요한 캐릭터 자세

아래는 제작할 자세의 종류입니다. 애니메이션 프레임 수는 시제품 검증 후 확정하며, 방향 수와 곱해 대량 생산을 먼저 시작하지 않습니다.

| 상태 | 캐릭터만으로 표현할 내용 | 포함하지 않을 물체 |
|---|---|---|
| 대기 | 빈손, 자연스러운 어깨와 팔, 읽히는 정면 방향 | 총기·가젯 |
| 이동 | 공통 체형을 유지하는 보행. 발 디딤과 무게중심 변화 | 총기·가젯 |
| 앉기 | 접힌 무릎과 낮아진 몸통을 새 실루엣으로 표현 | 총기·가젯 |
| 엎드리기 | 길어진 몸의 윤곽, 벌어진 다리, 자연스럽게 굽힌 팔꿈치 | 총기·가젯 |
| 투척 준비 | 몸통의 회전과 뒤로 당긴 팔. 빈손 | 수류탄·궤적 |
| 투척 방출·복귀 | 팔을 뻗고 원래 자세로 돌아오는 동작. 빈손 | 투척물·효과 |
| 설치·상호작용 | 전방 작업 공간으로 손을 뻗거나 낮춘 자세 | 설치 장치·태블릿·가방 |
| 레펠 준비·유지 | 하네스 착용, 벽에 맞춘 다리와 로프를 잡을 손의 위치 | 로프·총기 |

레펠은 벽과 수직 이동의 화면 투영을 먼저 확인합니다. 바닥에 서 있는 캐릭터의 회전만으로 처리하지 말고, 벽 접촉 자세와 손 위치를 별도로 설계합니다. 로프는 캐릭터가 아니라 독립 선 또는 에셋으로 합성합니다.

무기별 들기 예시 패널은 제작하지 않습니다. 추후 장착 기능에 팔 프리셋이 필요해도 **총기 없는 팔 포즈와 접점 데이터**로 분리해서 추가합니다. 무기 종류별 포즈 수는 그립 배치와 실제 합성 결과를 보고 결정합니다.

## 7. 런타임 합성 지침

### 7.1. 먼저 기존 구현을 확인합니다

저장소의 `AGENTS.md`, `README.md`, 현재 작업 지침과 렌더러를 읽고 실제 엔진·좌표계·그리기 순서·회전 중심을 확인합니다. 사용자 주 언어가 C#이라는 이유로 현재 프로젝트를 Unity로 단정하지 않습니다. 기존 라이브러리와 기본 기능을 우선하고, 이번 변경을 위해 새 엔진이나 무거운 래퍼를 도입하지 않습니다.

### 7.2. 포즈와 장착 위치를 함께 관리합니다

| 데이터 | 의미 |
|---|---|
| `pivot` | 포즈의 공통 회전·배치 기준점 |
| `weaponRoot` | 해당 포즈에서 무기를 배치할 기준점 |
| `gripMain`, `gripSupport` | 주손과 보조손 접점. 무기 쪽 대응점과 함께 검수 |
| `stockContact` | 개머리판이 있는 무기의 어깨 접촉 검수점 |
| `muzzle` | 무기 에셋에 정의하는 총구 위치. 발사 효과의 기준 |
| `gadgetSocket` | 별도 가젯이 배치될 위치 |
| `ropeGrip` | 로프와 빈손을 연결할 위치 |
| 그리기 순서 | 상태별 앞·뒤 팔, 손, 몸통, 무기 등의 겹침 규칙 |

위 이름은 의미를 전달하기 위한 권장 항목이며 기존 데이터 구조가 있으면 재사용합니다. 좌표 단위, 원점, 축 방향, 자르기 전후 기준을 함께 명시합니다. **실제 원본에서 측정하지 않은 좌표를 완성 데이터처럼 기록하지 않습니다.**

### 7.3. 합성 시 지켜야 할 원칙

- 무기는 미리 정한 포즈의 장착점에 맞춥니다. 주손 한 점만 맞추고 보조손·개머리판·몸통의 겹침을 방치하지 않습니다.
- 한 번의 위치·회전 조정으로 접점이 맞지 않으면 그립 구조에 맞는 다른 팔 포즈를 선택하거나 포즈를 보완합니다. 팔 길이 왜곡으로 해결하지 않습니다.
- 총기마다 실루엣과 상대 길이를 유지합니다. 모든 총기를 동일한 폭으로 강제 축소·확대하거나 가로세로 비율을 바꾸지 않습니다.
- 손 일부는 총기 앞에, 팔 일부는 뒤에 놓여야 할 수 있습니다. 모든 상태에 단일 그리기 순서를 강제하지 않습니다.
- 캐릭터, 무기, 가젯, 로프, 발사 효과는 서로 독립적으로 켜고 끌 수 있어야 합니다. 발사 화염은 무기 이미지에 고정하지 않습니다.
- 비무장 원화 납품과 실제 장착 검증을 구분합니다. 게임 안에서 임시 합성해 검수하는 것은 필요하지만, 그 합성본을 캐릭터 원본으로 저장하지 않습니다.

## 8. 파일·메타데이터 납품 기준

캐릭터 원본은 실제 알파가 있는 PNG로 전달합니다. 검정 배경이나 체크무늬 배경을 투명 배경처럼 이미지에 그리지 않습니다. 제목, 방향 글자, 표, 테두리, 워터마크, 무기 비교 패널은 에셋에 포함하지 않습니다.

동일 포즈군은 일관된 체형·축척·회전 기준을 유지합니다. 이미지 크기만 같게 맞추고 인물 크기가 프레임마다 달라지는 납품을 금지합니다. 해상도는 실제 화면의 표시 크기와 확대 범위를 확인해 정하며, `64×64`나 `128×128`을 검증 없이 확정하지 않습니다. 엎드리기와 투척처럼 윤곽이 길어지는 자세에 충분한 여백을 확보합니다.

가능하면 파츠가 분리된 편집 원본, 개별 PNG, 상태·프레임·피벗·소켓 정보를 함께 전달합니다. 자동 자르기를 사용하면 피벗·소켓의 좌표 보정 정보도 유지합니다.

권장 파일명 예시입니다. 실제 폴더·이름 규칙이 있으면 그 규칙을 따릅니다.

```text
base_idle_00.png
base_walk_00.png
base_walk_01.png
base_crouch_00.png
base_prone_00.png
base_throw_windup_00.png
base_throw_release_00.png
base_throw_recover_00.png
base_interact_00.png
base_rappel_00.png
```

실제로 방향별 제작을 선택한 경우에만 방향 코드를 추가합니다. 이름에 `N`, `NE` 등을 붙였다는 이유로 해당 방향이 검증되었다고 취급하지 않습니다.

앞서 생성한 예시 시트는 외형·포즈 참고용입니다. 실제 탑뷰 일치 여부, 방향 중복, 프레임 수, 균등 셀, 알파, 파츠 분리를 확인하지 않았으므로 **완성된 런타임 아틀라스로 자동 등록하지 않습니다.**

## 9. 유효한 총기 레퍼런스

이 목록은 캐릭터의 선화·색감·명암·재질감을 맞추기 위한 자료입니다. 총기를 캐릭터에 함께 그리거나 재제작하라는 지시가 아닙니다. 아래 설명만으로 아트 방향을 읽을 수 있으며, 이미지 판독은 필수 전제 조건이 아닙니다.

파일은 전달용 ZIP의 `references/` 폴더에 있습니다. 확인한 원본은 모두 `2172×724`, `RGBA`이며, 전달본은 픽셀 수정 없이 파일명만 정리했습니다. 정확한 모델명은 P90 외에 임의 확정하지 않았습니다.

### 제외한 자료

- 원본 파일: `3D08B8C7-7946-46FB-B4B1-F58423B6D3B9.png`
- 내용: **P90과 발사 화염이 한 이미지에 결합된 버전**.
- 처리: 유효한 레퍼런스·전달용 ZIP에서 제외합니다. 화염만 잘라 새로운 기준 원본으로 삼지 않고, 이미 제공된 P90 비발사형을 사용합니다.
- 원본 파일명과 전달 파일명의 대응, 치수, SHA-256 검증값은 `REFERENCE_MANIFEST.json`에 기록합니다. 이 JSON은 추적용이며 제작 요구사항은 본 문서에 모두 포함되어 있습니다.

## 10. 권장 작업 순서와 완료 기준

기존 구현 확인 → 공통 오퍼레이터 한 명의 대기·앉기·엎드리기 시제품 → 기존 총기와 임시 합성 → 실제 게임 표시 크기 검수 → 이동·투척·상호작용·레펠 확장 → 부대·개인별 외형 확장 순서로 진행합니다.

첫 시제품이 통과하기 전에는 모든 오퍼레이터와 방향을 대량 제작하지 않습니다. 장착 검증에서는 소형 무기, 일반 길이 무기, 긴 무기를 최소 한 가지씩 사용해 접점과 윤곽을 확인합니다.

### 검수 체크리스트

- [ ] 캐릭터 원본에 총기·가젯·로프·발사 효과가 포함되지 않았습니다.
- [ ] 무기별 들기 예시 패널과 이미지형 설명 문서가 납품 에셋에 들어 있지 않습니다.
- [ ] P90 화염 버전은 유효 레퍼런스에서 제외되고, 비발사형은 유지됩니다.
- [ ] 총기와 캐릭터의 시점·선화·명암·상대 축척이 실제 게임 화면에서 어울립니다.
- [ ] 모든 프레임에서 체형·피벗·알파 경계가 일관됩니다.
- [ ] 팔 이중 표시, 몸통 관통, 손의 공중 부유, 팔꿈치 역꺾임이 없습니다.
- [ ] 장착 합성에서 주손·보조손·개머리판 위치와 앞뒤 겹침이 검증되었습니다.
- [ ] 앉기와 엎드리기는 단순 축소가 아닌 별도 실루엣으로 구분됩니다.
- [ ] 투척·설치·레펠은 물체가 없는 캐릭터 자세로 납품하고 런타임 합성은 별도로 검증합니다.
- [ ] 레펠 자세와 로프 연결점이 실제 벽 표현에 맞습니다.
- [ ] 부대·오퍼레이터별 개성이 작은 화면에서도 구별됩니다.
- [ ] 기존 이동·전투·충돌·가젯 로직을 의도치 않게 변경하지 않았습니다.

검수 결과는 적용 파일, 확인한 화면·상태, 미해결 항목으로 구분해 기록합니다. 이미지를 생성한 것, 에셋을 적용한 것, 게임에서 검증한 것을 각각 별도 완료 상태로 보고합니다.
