## 이번 연결 범위

- 9개 PNG: 몸체 3방향, 헬멧·고글형 머리 3방향, 방독면형 머리 3방향. 모두 128×128이며 12명이 재사용합니다.
- 이름·기존 무기 목록은 유지합니다. 무기는 카빈·소음총·불펍·P90·정밀·볼트액션의 **6개 표현용 실루엣**입니다. 12종의 제조사 도면 고증이나 12명 전용 복장 완성으로 세지 않습니다.
- 주 Canvas 및 선수 카드 초상을 새 파츠에 연결했습니다. 몸체 작은 움직임, 방향별 파츠, 무기·손의 일체 반동, 앉기·다운의 간소화된 상태 표현입니다.
- 반동은 실제 shot 이후에만 발생하며 발사 순간의 총구는 기존 엔진 좌표를 보존합니다. 바닥 그림자는 Canvas가 그립니다.
- 전술 보기에서 선택한 아군의 시야만 벽·엄폐·활성 연막으로 잘라 표시합니다. 격자는 2m이며 붉은 병목 선은 지도 구조 표시로 적의 존재를 뜻하지 않습니다.
- 사진풍 걷기·장전·특수행동 시트를 추가 생성하지 않습니다. 세부 동작은 필요해진 파츠의 이동·회전 또는 소수 전환 프레임만 추가합니다.

## 다음 구현 순서

1. **가젯 대응의 한 맵 완성:** 보강→관통 파쇄, 연막→시야 차단, 카메라→관측/제거는 현재 연결. 투척물 요격, 전기/EMP, 이동 드론은 미구현입니다. 구현 전에는 편성에 완성된 능력으로 광고하지 않습니다.
2. **고유 장비 파츠:** 2종 공통 머리에서 각 오퍼레이터의 고유 헬멧·보호구·파우치로 확장. 부대의 실제 공통 지급품이라고 단정하지 않고 출처와 창작 범위를 기록합니다.
3. **행동 읽힘:** 장전의 탄창 파츠, 실제 투척 시 손에서 이탈, 설치·소생 중 손 위치, 틀 통과 전환을 같은 파츠로 구현. 현재 단순화된 표시를 세부 애니메이션 완성으로 세지 않습니다.
4. **맵 검증:** 두 거점 각각 독립적인 3개 침투 경로와 파괴 전후 대체 경로를 검증. 현재 추가 외벽 패널·실제 엄폐·2갈래 편성만으로 모든 사선이 25m 이내라고 주장하지 않습니다.
5. **후속 층 구조:** 계단/해치/높이/바닥 파괴/층간 탄도와 관측을 함께 설계한 뒤 수직 교전을 추가합니다.
