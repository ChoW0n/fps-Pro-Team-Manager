## 회귀와 근거

14개 스위트 중 11개 통과, tactical-pressure/combat-overhaul/playback-navigation 실패. 수정 전 HEAD 190797e의 별도 작업본에서도 같은 3개 실패를 재현했다. 원문에 적힌 '14개' 목록은 실제 13개 이름이므로 utility-inventory를 추가해 14개를 실행했다. 준비 단계와 맞지 않는 최초 배치·국면 기대가 포함돼 있지만, 장약·제압·수류탄 회피·방패·설치 표본 실패를 전부 검사 노후화로 단정하지 않는다. 임계값이나 assertion을 삭제하지 않았다.

원시 stdout/stderr/exitCode: `validation/qa-verify-suites.json`, 수정 전 결과: `validation/qa-verify-baseline.json`. 새 자동 검사 전체 출력: `validation/qa-verify-output.txt`, 수치: `validation/qa-verify.json`.

타입 검사·프로덕션 빌드, 실제 Canvas 16장면, 효과 수명/숨김/층/미래/미로딩 대체/동작 줄이기, 연막 픽셀·수명 검사는 통과했다. Canvas는 Skia 실행이며 브라우저·청음·실기기 성능 검사가 아니다. phone-retina-landscape p95 51.92ms 등으로 성능 합격을 주장하지 않는다.
