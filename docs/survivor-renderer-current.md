# Survivor 원본 기반 캐릭터 교체

최신 사용자 요청: OpenGameArt의 Animated Top Down Survivor Player를 기준으로 다시 제작한다. 앞선 도형 몸통·선 팔과 그 외형 승인 기준은 이번 요청으로 대체되었다.

## 적용

- `SurvivorParts`가 원본 몸통·머리·배낭·위팔·아래팔·손·다리·발 PNG를 조립한다. 기존 도형 신체 드로잉은 활성 렌더러에서 제거했다.
- 12명 모두 새 파츠를 사용하며 군장 표식 색/규모와 총기로 식별한다. 개별 얼굴·부대별 전용 복장 12세트를 새로 그린 것은 아니다.
- 총기 20종은 기존 탑뷰 원화를 유지한다. 새 신체에 맞춘 표시 장착점과 손 접점으로 연결하며 시뮬레이션 총구·히트박스·성능은 변경하지 않는다.
- 원본 발 애니메이션 81프레임: 정지 1, 걷기/달리기/좌우 이동 각 20. 이동 거리가 보행 위상을 진행하고 상체는 조준을 따른다.
- 원본 상체 Spine 타임라인은 이식하지 않았다. 기존 게임의 장전·반동·투척·설치 상태를 원본 파츠에 적용한다. 앉기와 방패는 원본에 없는 프로젝트 자세다.
- 포복은 삭제 상태 유지. 방패+주무장 금지, 보조무장 전용 고정 유지.
- 저동작 설정·일시정지·장전 취소·층 변경·다운 초기화 계약 유지.
- [아트 출처 및 재현](THIRD_PARTY_ART.md), [적용 시트](../validation/survivor-operator-sheet.png).

## 현재 검증 명령

- `node tests/survivor-renderer.cjs`: 원본 PNG 조립, 총기/손/총구, 방패 손잡이, 비활성 무장 숨김, 외형/판정 분리.
- `node tests/modular-operator-animation.cjs`: 이동·조준 2,560개, 장전 손 접점 100개, 시간/거리/중단 전환.
- `node tests/render-broadcast-canvas.cjs`: 실제 중계 컴포넌트를 Node Canvas로 실행. 브라우저 아님.
- 앱 TypeScript 및 Vite 빌드.

`operator-crouch-preview.cjs`, `operator-shouldering.cjs` 등의 과거 승인 외형 비교는 이전 코드 아트 회귀 자료이며 새 아트의 승인 기준이 아니다. 원본 상체 애니메이션 전체 이식, 개별 부대 복장, 실기기 시각 승인을 완료했다고 주장하지 않는다.

## 다음 채팅

`docs/ART_APPROVED.md`의 최신 지시와 이 문서를 먼저 읽는다. 사용자 피드백 없이 이전 도형 캐릭터를 다시 활성화하지 않는다. 기존 경기 구현 작업 분해 문서의 후속 코드 작업으로 이어갈 수 있다.

## 팔 자세 후속 교정

- 원본 소총·권총 정지 프레임을 직접 비교했다. 기존 조립은 팔 폭이 좁고 몸통이 아래팔을 가려 원본보다 가늘고 각진 팔을 만들었다.
- 어깨·팔꿈치 배치와 위팔/아래팔 두께를 조정하고 몸통 → 팔 → 머리 순으로 분리했다.
- 권총은 표시 배율 0.65를 이미지와 손 접점에 동일 적용한다. 총기 원화 파일은 재제작하지 않았으며 시뮬레이션 총구·성능 값도 유지한다.
- Survivor 480개 조건, 이동/조준 2,560개, 팔 접점 100개 통과. 실제 원본 애니메이션의 완전 복제나 사용자 시각 승인을 의미하지 않는다.
