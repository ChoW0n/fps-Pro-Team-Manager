# 연출·사운드·적 접촉 QA — 현재 기준 (2026-09-12)

원문 `presentation-and-sound-qa.md`를 현행 `main`의 실제 준비 입력으로 다시 측정했다. 원문의 당시 커밋과 현재 남산 2층 구현은 다르므로 숫자는 원문을 그대로 복사하지 않았다.

## 재현 범위

- 입력: 실제 준비 경로와 같은 즉시 진입, 진입로 0, 고정 시드 1~20

## 적을 보이게 하는 기준

라이브 경기에서 숨은 적의 현재 좌표를 상시 공개하면 감독 게임의 개인 관측 규칙을 깨고 AI 정보와 중계 정보가 달라진다. 대신 다음 세 계층으로 적 존재감을 만든다.

1. **직접 확인**: 현재처럼 실제 관측된 적의 완전 실루엣과 팀색 외곽선을 그린다.
2. **마지막 목격**: 관측이 끊긴 좌표를 3초 동안 점선 윤곽으로 남기고, 시간에 따라 희미하게 한다. 이름·체력·현재 행동은 표시하지 않는다.
3. **소리·정보 접촉**: 실제 `sound`·`intel` 사건이 팀에 전달된 경우에만 1.2초 방향 펄스 또는 익명 접촉 표식을 남긴다. 적의 정확한 현재 위치나 신원은 만들지 않는다.

이 구조는 사용자 요청의 “적이 안 보여 전장이 허전하다”를 해결하면서도 예측과 수색의 게임 규칙을 보존한다. 마지막 목격만 3초로 늘려도 현재 직접 관측 대비 적 접촉 시간이 5.2%에서 10.7%로 늘어난다. 더 긴 유지 시간은 현재 QA로 정당화하지 않는다.

## 2026-09-12 구현 반영

- 마지막 목격은 실제 관측이 끊긴 좌표에만 3초 동안 남긴다. 적의 현재 좌표·이름·체력은 추가로 만들지 않는다.
- 사용자가 제공한 총기 원화 29개를 `DRAFT ORDER/20-ART-REFERENCE/WEAPON-SOURCE-ORIGINALS`에 보관하고, 그 선 굵기·건메탈/올리브/탄색 배색·평면적 재질 묘사를 기준으로 장비 상태 시트와 사건 효과 시트를 다시 제작했다. 반향 표식·카메라·전력 노드·요격기는 정상/EMP 정지/탄 소진을 구분하고, 투척물·연막 단계·EMP·소리 위치·탄착·폭발·파쇄는 실제 가젯과 사건의 좌표·활성 시간에 맞춰 그린다. 원화가 아직 로드되지 않았을 때만 기존 도형으로 대체한다.
- AUBERT의 이동 드론은 제거하고 외곽에 고정하는 **반향 표식**으로 교체했다. 실제 적 발소리/설치음이 범위 안에 있을 때에만 팀 소리 보고를 만든다.
- 출전 버튼의 사용자 제스처에서 Web Audio를 연다. 총성·피격·설치·폭발/파쇄에 짧은 합성 신호를 연결했다. 발소리·음소거 제어·샘플 기반 사운드는 남은 작업이다.

## 구현 우선순위

### P0 — 중계 정보와 결정적 사건

- 마지막 목격 3초 페이드와 실제 소리·정보 접촉 펄스 **완료**
- 처치·다운·소생·설치·해체의 짧은 상태 연출
- 선택 선수의 최신 `goal`을 하단 한 줄 판단 티커로 표시
- `prefers-reduced-motion`에서는 카메라 흔들림·확대만 끄고 정보 표시는 유지

### P1 — 스프라이트 기반 이펙트·가젯·능력 표현 **1차 완료**

같은 미니멀 밀리터리 팔레트·굵은 외곽선·탑뷰 기준으로 다음을 개별 RGBA 스프라이트로 제작해 실제 사건에 연결한다.

| 분류 | 첫 제작 대상 | 실제 연결 사건 |
|---|---|---|
| 교전 | 총구 섬광, 탄착 파편, 피격 플래시, 다운 표식 | `shot`, `impact`, `downed`, `death` |
| 공용 가젯 | 연막 캔, 수류탄, 설치 방패, 보강 패널 | `smoke-thrown`, `grenade-thrown`, 준비·파쇄 |
| 고유 능력 | EMP 코일, 돌입 장약, 이동 드론, 전력 노드, 요격기 | `emp-pulse`, `breach-started`, `drone-deployed`, `power-deployed`, `interceptor-deployed` |
| 목표 | 설치 장치, 작동 LED, 해체 진행 링 | `planted`, `disabling`, `defused` |

스프라이트는 장식만으로 추가하지 않는다. 각 에셋은 실제 가젯 소유자·좌표·활성 시간·파괴 상태를 읽어야 하며, 엔진 피해·시야·승패 판정은 바꾸지 않는다.

### P2 — 사운드 **1차 완료**

Web Audio API로 총성·피격·폭발/파쇄·설치 신호를 1차 연결했다. 발소리 위치 병합·동시 3개 제한·배속 필터·음소거 토글은 남았다.

## 확인된 제한

- 이 QA는 현행 코드·고정 20시드 엔진 결과다. 실제 브라우저와 휴대폰에서 연출 밀도·오디오 자동 재생·성능을 검증하지 않았다.
- 3초 마지막 목격은 시뮬레이션 수치다. UI에 적용한 뒤 Canvas 렌더와 실제 중계 흐름으로 다시 확인해야 한다.
- 원문이 제안한 사운드 샘플 14개와 스프라이트는 아직 제작·연결하지 않았다.


## 2026-09-12 탑뷰·총성 재검수

- 기존 총성은 총기 구분 없는 저음 사각파 하강음이었다. oscillator를 제거하고 대역 제한 노이즈의 짧은 폭발음·기계음으로 교체했다. 기존 weaponHandling의 탄종/무기군과 MP5SD·AS Val 소음기 구분을 연결했다. 이는 임시 설계 합성음이며 실총 녹음·고증 완료가 아니다.
- 사건의 발사자 weaponName을 연결하고 거리 감쇠·좌우 배치를 적용했다. 미공개 적 사건, 일시정지·배속의 밀린 소리는 재생하지 않는다. 실내 반사·벽 투과 음향 모델은 미구현이다.
- 장비 아틀라스 v4를 수직 탑뷰로 재제작했다. 첫 결과의 체크무늬 배경을 불합격 처리하고 수정본의 RGBA·외곽 alpha=0을 확인했다. 장비 22~30, 투척물 14 월드 단위로 줄이고 설치 시 방향을 스냅샷에 저장했다. 벽 연결 장비는 벽 축에 정렬한다.
- 테스트의 이펙트 로더가 operators 폴더를 잘못 참조하던 결함을 수정했다. 이전 렌더 테스트 통과는 이펙트 원본 검증 근거가 아니었다. 수정 뒤 실제 Canvas 16개 시나리오 통과, 카메라 표시 화면 확인.
- 첨부 OPERATOR_SPRITE_GUIDE.md 반영. P90 화염 결합 원본은 새 제작 레퍼런스로 사용하지 않았다. 빈손 3포즈 시제품과 비교 화면을 public/art-review/operator-topdown-v1/에 추가했다. 원본에는 총기·가젯·로프가 없다. 생성된 셀 간 인체 위치가 달라 균등 아틀라스로 등록하지 않았다.
- 캐릭터 미해결: 대기 대비 앉기 윤곽 차이 부족, 세 총기의 주손·보조손·견착 접점 불일치 검수, 이동·투척·설치·레펠 포즈 미제작. 시제품을 경기 기본 캐릭터로 적용하지 않았다.
- 검증: TypeScript 검사·프로덕션 빌드·준비 단계 실제 20경기 검사·Canvas 16시나리오 통과. 브라우저 검증 스크립트는 작성했으나 Chromium 미설치와 다운로드 시간 초과로 실행 미완료. 실제 청음 품질 승인도 미완료.
