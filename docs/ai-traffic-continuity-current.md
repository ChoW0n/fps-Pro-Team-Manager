# AI 판단·통행 후속 — 2026-09-13

기준은 PR #9 병합 `7fb158140321185853f0c0516e0edcaa7be4a8e0`. 이번 범위는 **통행 재개 후 남는 대기 상태와 오래된 소리의 재선회** 두 결함이다. 전체 판단 왕복·통행 교착·공수 밸런스 해결 판정이 아니다. 브라우저 검증·새 에셋 생성·유료 API 사용은 하지 않았다.

## 재현과 수정

1. 실제 8경기의 `hold` 이동 스냅샷 15개는 창문/낮은 통로 통과에서 재현됐다. 대기 타이머가 있어도 통과 동작은 실제 이동을 재시도하는데, 성공 후 행동과 대기 타이머를 갱신하지 않았다. 실제 보행 성공 지점에서만 타이머를 지우고 `hold`를 `approach`로 전환한다. 벽·동료 충돌 검사와 양보·통행 우선권은 변경하지 않았다. 대기 타이머 동안 무조건 멈추는 과거 실패안을 재도입하지 않았다.
2. 소리 반응은 최근 직접 관측보다 오래된 소리에도 몸을 돌렸다. 원래 기억 갱신에 쓰던 0.8초 창과 최신 관측 시각을 회전에도 적용한다. 청각 기억 버퍼 2.5초는 보존하고, 새 소리에 같은 틱에 반응하면서 기존 단일 회전 한도를 유지한다. 적의 숨은 현재 좌표는 사용하지 않는다.

각 수정 전에 실패하는 검사를 실행했다. `navigation-traffic`의 재개 계약은 `hold !== approach`로, `sound-attention`의 최신 관측 우선 계약은 이전 총성 쪽으로 24도 회전해 실패했다. 실제 경기 감사도 `holdMoving: 15`로 실패했다. 기준이나 입력을 완화하지 않았다.

양보 경로의 반복 삽입 가설은 이번 8경기의 잔여 경로 20점 초과 추적으로 재현되지 않았다. 따라서 그 경로와 예약 소유권을 추측으로 바꾸지 않았다. 이는 모든 통행 교착이 없다는 증명이 아니다.
