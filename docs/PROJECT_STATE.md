# DRAFT ORDER — 이어서 작업할 때 읽는 요약

기준: 2026-09-12 인수인계 복원 및 후속 개선. 최신 사용자 결정이 이전 기획보다 우선합니다. 세부 이력은 Git에 보존하며 매번 대화 전체를 다시 읽지 않습니다.

## 목표와 고정 원칙

- 전술 FPS 구단 감독 게임. 준비·편성·전술을 선수가 실제로 수행하고 감독은 관전합니다.
- 5대5, 리스폰 없음, 공수 교대, 라운드 경제 없음. 결과 선결정 금지. 관전/비관전은 동일 시드·틱 엔진입니다.
- 개인 관측·팀 보고·마지막 목격·관전자 정보를 구분합니다. 숨은 평정심/팀 궁합은 숫자로 공개하지 않습니다.
- GitHub ChoW0n/fps-Pro-Team-Manager가 개발 원본. Replit은 Free 범위 동기화·실행만 요청합니다. 토큰 출력·파일 저장, 강제 푸시, 유료 전환 금지입니다.
- 존댓말, 짧은 한글 의도 주석. 검증·실제 적용·플레이 확인을 구분합니다. 작업 후 다음 추천 1~3개를 제시하고 사용자가 계시면 다음 작업을 선택받습니다.

## 최신 결정 — 이전 요청을 대체함

- 아트는 **미니멀 밀리터리**: 2~3등신, 저채도 군장색, 굵은 외곽선, 64/128px 파츠, 앞·뒤·옆 조립입니다.
- 실사형 전신 시트 대량 생성, 모든 프레임 512px 기준, 실사 맵/노이즈/후처리 확장은 중단했습니다. 기존 원본은 삭제하지 않고 이력으로 보존합니다.
- 몸체·머리·장비·무기와 손을 분리하고 실제 상태에 따른 작은 움직임을 사용합니다. 상세 고증을 추측으로 완료 처리하지 않습니다.
- 전술 지도는 실제 벽/통로/엄폐와 일치해야 합니다. 선택 아군의 시야는 전술 보기에 표시하며 미확인 적의 시야는 공개하지 않습니다.
- 가젯 조합은 실제 차폐·관측·파괴의 대응 관계입니다. 확정 승패 배율·보이지 않는 벽·15m 이후 무조건 빗나감·스폰 무적은 채택하지 않았습니다.

## 검증과 전달 상태

- 전술 10개, 전투 20개, 부상 12개 자동 검사 통과. 별도로 UI 5그룹, 36개 실제 파츠 합성, Canvas 10장면 검사와 타입 검사·빌드 통과.
- 브라우저 플레이는 접근 정책으로 미완료. 로컬 Skia/SSR 결과를 iPhone 15 성능 검증이라고 부르지 않습니다. 렌더 시간 변동도 남아 있습니다.
- 일반 8개 진단은 수비 전승이며 밸런스 해결이 아닙니다. 일반 4경기 소생 0회, 별도 실제 구조 입력에서는 소생 확인입니다.
- ZIP의 73개 파일과 패치 체크섬을 확인하고 GitHub main에 `ff5fad8`로 복원 완료. 로컬 복원 tree와 원격 tree가 일치합니다. 출처 불명 미커밋 원화는 적용하지 않았습니다.
- Replit은 `39126900ab6a198c73bdbc6ae38b878ebbb14682`에서 `ff5fad8` 포함, 기존 이력·설정 보존, 충돌 없음, 작업 트리 clean 및 개발 서버 실행을 보고했습니다. Git 가져오기·병합·실행만 수행했다고 보고했으며 실제 계정 요금 모드는 독립 검증하지 못했습니다. 공개 배포는 하지 않았습니다.

## 이번 후속 개선

- 창문·틀 통과 중 이탈해 경로가 끝나도 traversal이 남아 이동과 사격을 막던 버그를 수정했습니다. 완료된 경로에서 상태를 해제하고 다운 상태의 포복 제약은 보존합니다.
- 터치 선택 거리를 CSS 45px로 통일했습니다. DPR 3에서 실제 pointerup 처리의 중심 선택·빈 공간 미선택을 로컬 Canvas로 검사했습니다.
- 매 프레임 전체 경기 사건을 순회하지 않고 최근 8초만 역순 탐색합니다. 엔진의 현재 식별 목록을 재사용하고 공통 파츠와 미디어 질의 객체를 한 번만 준비합니다.
- 12명에 창작 벡터 군장 조합을 추가했습니다. 조끼·파우치·배낭·장비 운반 실루엣이며 정면·후면·측면마다 같은 무기를 들어도 12명이 서로 다른 픽셀로 조립됩니다. 새 가젯 기능이나 실부대 지급품 고증을 뜻하지 않습니다.
- 전술 10·전투 20·부상 12 검사, 통행 및 통과 상태 해제 검사, 36개 합성과 Canvas 11장면·터치 검사 통과. 타입 검사·빌드 통과. 클라우드 브라우저의 로컬 주소 접근 차단으로 실제 플레이와 휴대폰 성능은 미검증입니다.
- 같은 일반 시드 8개는 수정 후에도 수비 전승입니다(`validation/post-handoff-movement.json`). 이동 상태 버그 수정과 공수 밸런스 완료를 구분합니다. 설치 후 경계 위치와 재진입 대응 조정이 남습니다.
