## 개별 생성 스프라이트로 전환 — 최우선 최신 결정

- 사용자가 코드 총기 방식과 늘어나는 투척 팔을 거부했습니다. 총기 다각형/사각형 생성기를 제거하고 이미지 생성 도구로 제작한 개별 PNG 12종을 연결했습니다. 기존 코드 총기를 폴백으로 재사용하지 않습니다.
- 모든 작업 시작 전에 현재 목표·완료 조건·금지 방식·근거에 맞게 프롬프트를 재작성합니다. AGENTS와 마스터 프롬프트에 반영했고 이번 내용은 sprite-production-current.md에 있습니다.
- 원본 RGBA 스프라이트를 그대로 저장합니다. 총구/파지/지지 손/탄창 좌표를 개별로 정렬하며, 실제 총구·탄도 계산은 변경하지 않았습니다. 첫 L119 수정 시안의 RGB 체크무늬 2장은 게임 에셋에서 제외했습니다.
- 엔진의 축소 캐시와 PNG 알파 기반 외곽선으로 작은 화면 가독성을 보완합니다. 이것은 기존 코드 총기 도형 재사용이 아닙니다. 생성 PNG 12개 합계 약 8.8MB이므로 실제 모바일 초기 로딩 검수가 남습니다.
