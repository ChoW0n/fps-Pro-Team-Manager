# DRAFT ORDER — 현재 상태와 다음 작업

기준일: 2026-09-13. 현재 코드 정본은 GitHub `main`이다. 아트·AI·UI의 과거 “최신” 기록은 [이력](PROJECT_STATE_HISTORY_20260913.md)에 보존했다.

## 확정 기준

- 플레이어는 감독이다. 편성·오퍼레이터·작전을 준비하고 5대5 무리스폰 경기를 관전한다.
- 캐릭터 인체 형태와 비율은 Riley Gombart의 **Survivor 원본**을 최우선으로 한다. 이전 도형 체형·통짜 시트·과거 승인 비율을 되살리지 않는다.
- 서기·앉기만 사용한다. 방패는 보조무장 전용이며 주무장과 함께 표시하거나 사용하지 않는다.
- 신체 파츠와 총기 표시 변경은 판정·능력치·시뮬레이션 총구와 분리한다.
- 아트 재설계는 이번 단계를 끝으로 멈추고, 새 작업은 아래 우선순위 한 개씩 진행한다.

## 다음 작업 — 순서 고정

1. **AI 판단·통행 안정화**: 고정 시드 8경기의 판단 변경과 실제 이동 궤적을 연결하고 가장 큰 원인 하나만 수정한다. 공수 승률·사망 수·명중률을 같은 입력으로 비교한다.
2. **관전 한 라운드 흐름**: 준비→교전→설치→종료의 상태 연결과 모바일 정보층은 구현·정적 검증했다. 실제 휴대폰에서 3초 판독과 겹침을 사용자/Claude가 확인한다.
3. **남은 음향·장비 고증**: 무기군 식별과 거리/실내외 소리, 개별 복장을 별도 작업으로 다룬다.
